# 02 チート能力・スキル・ステータスの型

異世界ものの主人公が持つ規格外の力(いわゆるチート)と、それを支えるスキル・ステータス・レベル・ギルドランクの仕組みを整理する。個々の作品の設定は写さず、繰り返し出てくる型として抽象化した。

手がかりは、ピクシブ百科事典・ニコニコ大百科の「チート」「鑑定」「アイテムボックス」「外れスキル」「ステータスオープン」「冒険者ギルド」等の項目、TV Tropes の Level Up / Status Screen / Game-Breaker / Overpowered Protagonist / Bag of Holding / Power Copying 系の項目、Wikipedia の LitRPG の項目、および作品群についての一般的な知識。

---

## 1. チートの大分類

| 分類 | 中身 | 例 |
|---|---|---|
| 情報系 | 他人の知らないことを知る | 鑑定、予知、原作知識、地図 |
| 物流系 | 物を運ぶ・取り出す・買う | アイテムボックス、ネットショッピング、転移 |
| 成長系 | 強くなる速度が違う | 経験値倍増、成長促進、上限なし |
| 戦闘系 | 直接強い | 全属性魔法、剣聖、無限魔力 |
| 生存系 | 死なない・死んでもやり直す | 不死、自動回復、死に戻り |
| 生産系 | 物を作る | 創造、錬成、鍛冶、料理 |
| 支配系 | 他者を従える | テイム、魅了、眷属化 |
| 収奪系 | 他者の力を取る | スキル強奪、捕食、コピー |
| 運・確率系 | 偶然を味方にする | 幸運値MAX、ガチャ |
| 知識系 | 前世の学問・技能 | 医療、農業、化学、料理、工学 |
| 隠蔽系 | 正体を隠す | ステータス偽装、気配遮断 |
| 社会系 | 人に好かれる・地位を持つ | 魅力、カリスマ、神の加護の称号 |

## 2. チートの一覧と生存への効き方

「生存への効き方」は、そのチートを持った主人公が一生のうちで死ににくくなるのか、逆に危険を呼ぶのかを1行で書いた。頻度は作品群での出現の多さの目安。

### 2.1 情報系

| # | チート | 中身 | 頻度 | 生存への効き方 |
|---|---|---|---|---|
| 1 | 鑑定 | 人・物・魔物の名前、能力、状態、品質が見える | よくある(ほぼ必須) | 毒や罠や格上の敵を事前に見抜けるので、不意打ちの死を大きく減らす |
| 2 | 上位鑑定・神眼 | 隠蔽されたステータスや嘘、未来の可能性まで見える | たまに | 裏切りや偽装を見破り、暗殺による死を減らす |
| 3 | 予知・未来視 | 少し先、または遠い未来が見える | たまに | 致命的な出来事の回避に効くが、予知を狙う権力者に囚われやすい |
| 4 | 原作知識 | ゲームや小説の展開を知っている | よくある(ゲーム世界転生) | 決まった死亡イベントを避けられる。原作から外れるほど効き目が落ちる |
| 5 | マップ・探知 | 周囲の地図と、敵味方の位置が見える | よくある | 待ち伏せや迷子を防ぎ、探索中の死を減らす |

| 8 | 危機察知・直感 | 危ないと感じる勘が働く | よくある | 不意打ちと罠による死を大きく減らす |
| 9 | 読心 | 他人の考えが読める | まれ | 裏切りを防ぐが、人間不信になり孤立しやすい |
| 10 | 千里眼・遠見 | 遠くの場所が見える | たまに | 偵察で戦争や討伐の生存率が上がる |

### 2.13 「外れスキルが実は最強」の型

追放ものと無能扱いものの中心。普通の人が使うと役に立たない、あるいは名前が弱そうなスキルが、使い方次第で規格外に化ける。

| 外れに見えるもの | 化け方の型 |
|---|---|
| 掃除・洗濯 | 汚れ・呪い・状態異常・存在そのものを「消す」 |
| 料理 | 魔物を食材として扱い「さばく」=解体が一撃の攻撃に |
| 農業・耕す | 地形操作・大地の魔法に |
| 裁縫・糸 | 糸で拘束・切断 |
| 植木・庭師 | 植物の支配 |
| 収納(小容量) | 容量無制限・敵や魔法を収納して返す |
| 荷物持ち・ポーター | 重さの操作 |
| 鑑定のみ | 鑑定の上位で弱点が全部わかる |
| 村人・平民 | 全職業の補正を少しずつ持つ |
| 遊び人 | 何にでもなれる(転職の自由) |
| 一つだけの初級魔法 | 熟練度で上位魔法を超える |
| 逃げ足 | 速度・回避の頂点に |
| 睡眠 | 寝ている間にレベルが上がる |
| 毒・呪い | 敵にとっての致命傷 |
| 防御のみ | 絶対防御・反射 |
| 文字化けしているスキル | 誰も読めないだけで最上位 |
| レベル1・レベル固定 | 経験値を別のものに変換 |
| 「なし」(スキルを授からなかった) | 制限がないので全部覚えられる |

生存への効き方: 序盤は役立たず扱いで追放・冷遇されるので死にやすい。化けた後は大きく上向くが、元の所属先が取り戻しに来たり逆恨みしたりする。

## 3. スキルの仕組みの型

### 3.1 スキルの入手方法

| 型 | 中身 | 頻度 |
|---|---|---|
| 授与の儀 | 一定年齢(5歳・10歳・15歳など)で神殿や教会で授かる | よくある |
| 生まれつき | 生まれたときに決まっている | よくある |
| 練習・熟練 | 繰り返すと覚える | よくある |
| レベルアップ | 上がると覚える、またはポイントで取る | よくある |
| スキルポイント振り分け | ポイントを自分で割り振る | よくある(LitRPG) |
| スキルの書・巻物 | 読むと覚える | たまに |
| 魔物の討伐・捕食 | 倒したり食べたりすると得る | たまに |
| 称号の副産物 | 「ドラゴン殺し」の称号で竜特効が付く | たまに |
| 職業・クラス | 職業に付随するスキル | よくある |
| 継承 | 親や師から受け継ぐ | まれ |

### 3.2 スキルの等級

- 数字型: レベル1〜10、熟練度0〜100
- 文字型: 下級・中級・上級・特級・神級
- 英字型: F〜S、SS、SSS、EX
- 色型: 白・緑・青・紫・橙(ゲームのレアリティ)
- 名前の格上げ型: 剣術→剣技→剣聖→剣神(上位に進化する)
- ユニーク型: 「通常スキル」「レアスキル」「ユニークスキル」「エクストラスキル」「固有スキル」「アルティメットスキル」
- 権能・神格スキル: 神に近い力。持つ者は世界に数人

### 3.3 スキルの数の制限

- 普通の人は1〜3個、優秀な人で5個程度、主人公は数十個
- スキル枠(スロット)が決まっていて、入れ替えが必要
- 同時発動の上限

### 3.4 職業・クラス

- 戦士系: 剣士・騎士・戦士・槍使い・格闘家・狂戦士
- 魔法系: 魔法使い・賢者・魔導士・召喚士・死霊術師
- 支援系: 僧侶・神官・聖女・吟遊詩人・付与術師
- 斥候系: 盗賊・斥候・狩人・弓使い・暗殺者
- 生産系: 鍛冶師・錬金術師・薬師・料理人・農民・商人・裁縫師・建築士
- 特殊系: 勇者・魔王・剣聖・賢者・テイマー・遊び人・村人
- 上位職への転職(戦士→騎士→聖騎士)、複数の職の兼業、隠し職業

## 4. ステータスの型

### 4.1 ステータス画面の出し方

| 型 | 中身 | 頻度 |
|---|---|---|
| 「ステータスオープン」と唱える | 本人にだけ見える半透明の窓が出る | よくある |
| 念じると出る | 声に出さずに確認 | よくある |
| 鑑定板・水晶・ギルドカード | 道具を使わないと見られない | よくある |
| 他人には見えない | 自分だけの特権 | よくある |
| 世界の全員が見られる | 当たり前の仕組みとして社会に組み込まれている | たまに |
| ステータスの概念がない世界に、主人公だけ見える | システムが主人公だけのもの | たまに |
| システム音声・通知 | 「レベルが上がりました」と頭の中で声がする | よくある |

### 4.2 よく出る項目

- 名前・年齢・種族・性別
- 職業(クラス)・称号
- レベル
- HP(体力)・MP(魔力)・SP(スタミナ)
- 筋力(STR)・体力・耐久(VIT)・敏捷(AGI/DEX)・知力(INT)・精神(MND/WIS)・魅力(CHA)・幸運(LUK)
- 攻撃力・防御力・魔法攻撃力・魔法防御力
- スキル一覧(通常・固有・ユニーク)
- 加護(神の名前つき)
- 称号(竜殺し・転生者・異世界人・神の使徒など)
- 状態(健康・毒・呪い・空腹)
- 賞罰(犯罪歴が表示される世界もある)
- 所属(ギルド・国・パーティ)

### 4.3 ステータスの数値の目安の型

作品ごとに桁はまちまちだが、型としては次のような関係がよく使われる。
- 一般人: 各数値10前後、レベル1〜10
- 一人前の冒険者: 数値50〜200、レベル20〜40
- 騎士団長・Aランク: 数値数百〜千、レベル50〜70
- 英雄・勇者・Sランク: 数値数千、レベル80〜99
- 主人公: 桁が一つ二つ違う。または「測定不能」「∞」「???」と表示される
- レベルの上限は99、100、255、999など。主人公は上限を越える

### 4.4 ステータス画面のお約束

- 数値が高すぎて鑑定した人が腰を抜かす
- 称号欄に「異世界人」「転生者」と出ていて慌てて隠す
- スキル欄の一部が文字化けしている、または「???」
- 加護欄に聞いたこともない神の名前がある
- ステータスは低いがスキルだけ異常
- 年齢の割に数値が高すぎる幼児

## 6. 冒険者ギルドとランクの型

### 6.1 ランクの表し方

| 方式 | 並び | 頻度 |
|---|---|---|
| アルファベット | F・E・D・C・B・A・S(上にSS・SSS) | よくある(最多) |
| 金属 | 銅(ブロンズ)・鉄・銀(シルバー)・金(ゴールド)・白金(プラチナ)・ミスリル・オリハルコン・アダマンタイト | よくある |
| 宝石・色 | 白・黒・赤・青、または翡翠・紅玉・金剛石 | たまに |
| 数字 | 10級〜1級、または1つ星〜10つ星 | たまに |
| 称号 | 見習い・一人前・熟練・達人・英雄 | たまに |

### 6.2 ランクの意味の目安(アルファベット式の典型)

| ランク | 中身 | 全体の中の割合の目安 |
|---|---|---|
| F | 登録したての見習い。薬草採取・雑用 | 多い |
| E | 新人。弱い魔物の討伐 | 多い |
| D | 一人前の入り口 | 多い |
| C | 一人前。多くの冒険者がここで止まる | 中くらい |
| B | ベテラン。地域で名が知られる | 少ない |
| A | 一流。国から指名依頼が来る | まれ |
| S | 英雄級。国に数人。災害級の魔物に対抗 | ごくまれ |
| SS・SSS | 伝説・人外。歴史に数人 | 伝説 |

### 6.3 ギルドのお約束

- 登録時に水晶に手をかざして魔力や数値を測る(主人公は水晶を壊す・光らせすぎる)
- 受付嬢が看板役。主人公の担当になる
- 新人に絡む先輩冒険者(返り討ちにされる)
- 依頼掲示板。常設依頼と指名依頼
- 実績を積むとランクアップ試験

- 素材の買い取り窓口。アイテムボックスから大量に出して騒ぎになる
- ランクに応じて国家間の移動の自由や税の免除がある
- 大規模な魔物の襲来(スタンピード)で強制招集される
- ギルドは国から独立した組織、という建前

### 6.4 他のギルド

商人ギルド・魔術師ギルド・鍛冶ギルド・錬金術師ギルド・盗賊ギルド(闇ギルド)・料理人ギルド・テイマーギルド。主人公が生産職なら、こちらのランクと登録が中心になる。

## 7. チートの代償と副作用の型

チートは強いほど、何かを呼び寄せる。物語ではここが波乱の源になり、一生のシミュレーションでは死因と人生の転機を作る材料になる。

### 7.1 社会からの反応

| 型 | 中身 | 起きやすいチート | 頻度 | 生存への影響 |
|---|---|---|---|---|
| 国に狙われる・囲い込まれる | 王家が取り込もうとする。断ると反逆者扱い | 全属性魔法・無限魔力・創造・アイテムボックス・前世知識(火薬) | よくある | 中程度下向き(断った場合は大きく下向き) |
| 戦争に駆り出される | 兵器扱いで前線へ | 戦闘系全般・勇者・軍事知識 | よくある | 大きく下向き |
| 魔王・強大な存在に警戒される | 芽のうちに摘もうと刺客を送られる | 勇者・限界突破・スキル強奪 | たまに | 中程度下向き |
| 教会に異端視される | 神の領域を侵す、悪魔憑きと疑われる | 創造・魔法創造・死霊術・前世知識(医療)・転生者であること | よくある | 中程度下向き(異端審問・火刑) |
| 貴族に妬まれる | 平民の成り上がりが気に食わない | 成り上がり・内政チート | よくある | 小さく下向き(暗殺・陰謀) |
| 商人ギルドとの利権争い | 新商品が既存の商売を壊す | ネットショッピング・料理知識・魔道具 | たまに | 小さく下向き |
| 誘拐・拉致される | 能力目当てでさらわれる | 生産系・聖女・予知・美貌 | たまに | 中程度下向き |
| 実験体にされる | 不死や特異体質を研究したがる | 不死・超再生・特殊な種族 | たまに | 中程度下向き |
| 指名手配・懸賞金 | 罪を着せられる、または本当に暴れた | スキル強奪・死霊術・魔王側 | たまに | 大きく下向き |
| 恐れられて孤立する | 強すぎて誰も近寄らない | 収奪系・読心・規格外の戦闘力 | たまに | 小さく下向き(助けがない) |
| 縁談が殺到する | 血を取り込みたい家が群がる | 規格外の才能全般 | よくある | ±0(人間関係イベントが増える) |
| 有名になりすぎる | 二つ名がつき、どこに行っても騒がれる | 全般 | よくある | 小さく下向き |

### 7.2 能力そのものの代償

| 型 | 中身 | 頻度 | 生存への影響 |
|---|---|---|---|
| 寿命を削る | 使うたびに命が減る | たまに | 寿命が大きく縮む |
| 心が削れる | 死に戻りの記憶の蓄積、殺した相手の記憶が流れ込む | たまに | 精神崩壊・自死のリスク |
| 人間性を失う | 強くなるほど感情が薄れる、魔物に近づく | たまに | 人間関係の破綻 |
| 記憶を失う | 使うたびに思い出が消える | まれ | 家族を忘れる |
| 体の一部を失う | 目・腕・声を代価に | まれ | 戦闘力は上がるが生活が不便 |
| 制御できない暴走 | 感情が高ぶると勝手に発動 | たまに | 周りを巻き込み、討伐対象になる |
| 成長の停止 | 不老の代わりに子を持てない、体が子どものまま | たまに | 家系が途絶える |
| 呪い | 加護の裏に呪いがある(女難・不運・短命) | たまに | 呪いの種類による |
| 契約・取り立て | 神や悪魔に後で何かを差し出す | まれ | 人生の後半に大きな不幸 |
| 魔力酔い・反動 | 大技の後に寝込む | よくある | 大技の後の隙で死ぬことがある |
| 周りが不幸になる | 主人公の運の良さが周りから運を吸う | まれ | 親しい人が早死にする |

### 7.3 チートを隠す理由と、ばれる場面

隠す理由: 囲い込み・戦争・異端審問・嫉妬を避けたい、平穏に暮らしたい。

ばれる場面の型:
- 人前で魔物から誰かを救うとき、加減ができない
- 魔力測定・ステータス鑑定の公式な場
- 学園の実技試験・決闘
- 災害級の魔物の襲来で、使わないと街が滅ぶ
- 大切な人が死にかけている
- 酒の席で口を滑らせる
- 鑑定持ちの他人に見抜かれる
- 作った道具や料理が異常に良すぎて出所を探られる

## 8. 欧米 LitRPG と韓国ウェブ小説のシステム的な型

日本のなろう系とは少し違う形で発達した型。

- システム降臨: ある日、地球の全人類にステータス画面が出現する。チュートリアルを生き残れないと死ぬ
- 塔・ダンジョン攻略: 階層を上るごとに報酬。上位層ほど死亡率が高い
- ハンター: 現代都市に出現する門から魔物が出てくる。覚醒者がランク付けされる(E〜S)
- 職業の希少度: 誰も持っていない固有職業を主人公だけが引く
- 隠しクラス・隠しクエスト: システムの抜け穴を探す
- ビルド最適化: 数値の割り振りとスキルの組み合わせを詰める楽しみ
- 称号・実績: 世界初の達成で特別報酬
- 罰則: クエスト失敗でペナルティ(能力の低下・死)
- システムが何者かという謎(神・宇宙人・管理者)
- ダンジョンコア: 主人公がダンジョンそのもの。冒険者を誘い込んで糧にする
- 拠点づくり: 村を育て、住人を守り、防衛戦をする
- 回帰者・転生者・憑依者の三者が同じ世界に共存する

## 10. シミュレーションへの使い方

チートは「戦闘で死ににくくする」「病気で死ににくくする」「寿命を延ばす」「狙われやすくする」の四つの軸に効くと考えると扱いやすい。ゲーム内では各チートに次の数値を持たせることを提案する。

- combat_death_mod: 戦闘・事故による死亡確率への倍率
- disease_death_mod: 病死・疫病死・産褥死への倍率
- lifespan_mod: 寿命の基本値への倍率または加算
- attention: 国・教会・魔王・犯罪者に目をつけられやすさ(0〜3)
- 必要なら starvation_mod(餓死・遭難死)、assassination_mod(暗殺・毒殺)

以下、倍率は 1.0 が無影響。1.0 未満は死ににくく、1.0 より大きいと死にやすい。attention は高いほど「狙われる」系のイベントを引く確率を上げる係数として使う。数値はゲームを回して調整する前提の初期値。

### 10.1 チートの列挙値と初期値

| id | 頻度 | combat | disease | lifespan | attention | 備考 |
|---|---|---|---|---|---|---|
| appraisal(鑑定) | よくある | 0.85 | 0.95 | - | 0 | 毒殺回避にも効く(assassination 0.8) |
| divine_eye(上位鑑定) | たまに | 0.8 | 0.9 | - | 1 | assassination 0.6 |
| precognition(予知) | たまに | 0.7 | 0.9 | - | 2 | 権力者による幽閉イベントを有効化 |
| plot_knowledge(原作知識) | よくある | 0.7 | 0.9 | - | 0 | 効果は年齢とともに薄れる(原作から外れる)。40歳以降は1.0に戻す案 |
| map_detection(マップ・探知) | よくある | 0.85 | - | - | 0 | starvation 0.8 |
| sage_voice(頭の中の相談相手) | たまに | 0.85 | 0.9 | - | 0 | |
| danger_sense(危機察知) | よくある | 0.8 | - | - | 0 | assassination 0.7 |
| mind_reading(読心) | まれ | 0.9 | - | - | 1 | 孤立イベント+、assassination 0.5 |

### 10.2 抽選の重みと個数

- 重みの目安: よくある=10、たまに=4、まれ=1
- 個数の目安: 神との面会あり 2〜4個、面会なし 1〜2個、謝罪する神 +1、尊大な神 -1、チートなし(完全に素の転移者)も5%くらいで入れると、素の異世界の厳しさが見えて面白い
- 必須寄りの3種(鑑定・アイテムボックス・言語理解)は、召喚・転移のときに独立に50%ずつ付ける案

### 10.3 attention(注目度)の扱い

チートの attention を合計し、0〜3は平穏、4〜6は目をつけられる、7以上は国家・教会・魔王のどれかとの衝突が人生のどこかで確実に起きる、という段階にする。

attention が高いときに引くイベント表:
| イベント | 主な発生源 | 結果の分岐 |
|---|---|---|
| 王家からの召し抱え | 戦闘系・生産系 | 受ける(以後戦争招集+) / 断る(反逆者扱い、逃亡生活) |
| 戦争への招集 | 戦闘系・軍事知識・火薬 | 生還 / 戦死 / 英雄化 |
| 異端審問 | 創造・魔法創造・死霊術・医療知識・転生者の発覚 | 無罪 / 追放 / 火刑 |
| 魔王の刺客 | 勇者・上限なし・強奪 | 撃退 / 死亡 |
| 誘拐 | 生産系・聖女・予知・美貌 | 救出 / 自力脱出 / 監禁生活 |
| 実験体 | 不死・超再生 | 脱出 / 長い監禁 |
| 嫉妬した貴族の陰謀 | 成り上がり・内政 | 失脚 / 返り討ち / 暗殺 |
| 縁談の殺到 | 全般 | 結婚イベントへ |
| 指名手配 | 強奪・死霊術・魔王側 | 逃亡 / 捕縛・処刑 |

status_disguise・stealth・shapeshift などの隠蔽系は attention を下げる。ただし「ばれる場面」(7.3)を年に一定確率で判定し、ばれたら隠していた分の attention が一気に戻る、という形にすると物語らしくなる。

### 10.5 年齢との関係

一生をシミュレートするので、チートの効き目が年齢で変わるとリアリティが出る。
- 成長系(経験値倍増・成長促進・上限なし): 10〜20代は効果小、30代以降に効果最大
- 原作知識: 原作の終わる年齢(10代後半〜20代)を過ぎると効果が薄れる
- 外れスキル: 覚醒年齢までは不利、覚醒後に有利
- 捕食・吸収: 幼少期は不利、成長後に有利
- 身体系(超人の肉体・剣聖): 50代以降に少しずつ衰える(不死・超再生を除く)
- 生産系・知識系: 年を取るほど効く(老いても役に立つ)。老後の生存に強い
- ログボ・デイリー報酬: 年数に比例して強くなる

### 10.6 ギルドランクの列挙値

冒険者を職業として選んだときに使う。
- rank: F / E / D / C / B / A / S / SS(伝説)
- 金属表記を選んだ世界: 銅 / 鉄 / 銀 / 金 / 白金 / ミスリル / オリハルコン / アダマンタイト
- 昇格の目安(一般人): F→C に5〜10年、多くはCで引退。B以上は全体の1割、Aは数%、Sは国に数人
- チート持ちの昇格: 経験値倍増や戦闘系で昇格年数を1/2〜1/5に
- ランクごとの年間戦闘死亡率の目安(現地の一般冒険者、チートなし): F 3% / E 4% / D 5% / C 4% / B 3% / A 2% / S 1%。下位ほど無謀で死にやすく、上位は経験で死ににくい、という型。ただし上位ほど災害級の依頼を受けるので、S は「災害級イベント」を別表で引く
- 引退の型: 怪我で引退 / 結婚して引退 / ギルドの職員・教官になる / 店を開く / 貴族に叙される

### 10.7 ステータス表示の型(UI用)

- display_style: window(半透明の窓) / crystal(水晶の鑑定) / guild_card(ギルドカード) / voice(システム音声だけ) / none(ステータスの概念がない世界)

### 10.8 最低限の実装の提案

最初の版では次だけ持てば一生のシミュレーションは回る。
1. チートは 10.1 の表から「よくある」の30種程度
2. 各チートに combat / disease / lifespan / attention の4値
3. attention の合計で 10.3 のイベント表を引く確率を決める
4. 強いチートに 10.4 の代償を確率で付ける
5. 年齢による効き目の変化(10.5)は、成長系と原作知識と外れスキルの3つだけ先に入れる

これで「強いのに早死にする勇者」「地味な薬師が一番長生きする」「全部隠して平穏に老いた最強」のような、型どおりで、しかも型を裏切る人生が出てくるはず。
