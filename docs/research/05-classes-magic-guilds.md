# 05 職業・魔法・ギルド

異世界での一生をランダムに回すとき、職業は「どれくらいの年齢から何をして、どれくらいの確率で死に、何歳で引退するか」を決める。魔法の体系は、その世界で怪我や病気がどれくらい治るか、つまり死亡率の底を決める。冒険者ギルドや騎士団や教会は、人生の節目(入会、昇格、引退、破門)のイベントの供給源になる。

この資料では、ファンタジー、なろう系、TRPG、JRPG、LitRPG で繰り返し使われる型を一般化して整理する。特定作品の固有名詞や設定は使っていない。最後に、ゲームで使える列挙値と、職業ごとの年間死亡リスクの目安を、現実の危険職業の統計と並べて示す。

---

## 1. 職業の考え方

ジャンルの職業には、大きく二つの系統が混ざっている。

- 戦闘クラス: TRPG や JRPG 由来。戦士、魔法使い、僧侶、盗賊の4つを基本形に、組み合わせや特化で派生する。パーティの役割(前衛、後衛、回復、斥候)と結びついている。
- 生活職・生産職: なろう系で存在感が増した。鍛冶師、錬金術師、薬師、商人、農民、料理人。戦わない人生、戦闘職を支える人生として描かれる。

ランダム人生ゲームでは、戦闘クラスを選ぶ人は少数派で、大多数は農民や職人として一生を終える、という比率にしておくと世界の手触りが出る。前近代の人口の大半は農業に従事していたので、冒険者は人口のごく一部(数%以下)とするのが自然。

職業を決める要素の型は次のとおり。

| 決め方の型 | 内容 | ゲームでの表現 |
|---|---|---|
| 生まれ | 家業を継ぐ、身分で決まる | 親の職業から高確率で継承 |
| 天職・加護 | 成人の儀式で神から職業(ジョブ)を授かる | 15歳前後で抽選イベント、変えられないか変えにくい |
| 適性 | 魔力量や身体能力で向き不向きが決まる | 能力値で選択肢をしぼる |
| 自由選択 | 学校、弟子入り、ギルド登録で決まる | 人生の分岐イベント |
| 転職 | 経験を積んで上位職や別職に移る | 一定年数・実績で発生 |

なろう系では「成人の儀式で外れの天職を引いた主人公が、実はそれが最強だった」という型が非常に多い。ランダム人生では、外れ職業を引いて普通に苦労して終わる人生も同じくらい起きていい。

## 2. 職業カタログ(剣と魔法の世界)

各職業について、役割、就く年齢、典型的な人生、死にやすさ、上位職を書く。年間死亡リスクは「その職業に従事している年の、外因死の上乗せ」の目安で、詳しい表は最後の節にまとめる。

### 2.1 戦士

- 役割: 前衛。重い武器と鎧で敵を受け止める。
- 就く年齢: 15歳前後。村の若者が冒険者ギルドに登録する、兵士として徴集される、の二通り。
- 典型的な人生: 傭兵か冒険者として10〜20年、体が衰える30代後半から40代で引退。引退後は衛兵、教官、酒場の主人、農民に戻る。
- 死にやすさ: 高い。前線に立つので負傷の頻度が多い。
- 上位職: 剣士、騎士、狂戦士、重戦士、将軍。

### 2.2 剣士

- 役割: 剣技に特化した前衛。戦士より技巧寄り。
- 就く年齢: 道場や剣術の師匠のもとで10歳前後から修行し、15〜18歳で独り立ち。
- 典型的な人生: 冒険者、貴族の護衛、剣術道場の師範。
- 死にやすさ: 戦士よりやや低い(回避と技術)が、決闘や果たし合いの死亡がある。
- 上位職: 剣聖、魔法剣士、侍(東方系)。

### 2.3 騎士

- 役割: 主君に仕える重装の戦士。乗馬、槍、盾。
- 就く年齢: 貴族の子弟が7歳前後で小姓、14歳前後で従騎士、20歳前後で叙任される、という中世の型がそのまま使われる。
- 典型的な人生: 騎士団に所属し、戦争や魔物討伐に出る。領地を持つ者は中年以降に統治者になる。
- 死にやすさ: 戦時は高い。平時は低い。身分が高いので捕虜になって身代金で助かる確率がある(中世の騎士戦争の特徴)。
- 上位職: 聖騎士、近衛騎士、騎士団長、竜騎士。

### 2.4 魔法使い(魔術師)

- 役割: 後衛の攻撃役。属性魔法で敵を一掃する。
- 就く年齢: 魔力の適性が見つかる幼少期から師匠か魔術学院で学び、15〜20歳で一人前。
- 典型的な人生: 冒険者、宮廷魔術師、学院の研究者、魔道具の職人。研究者は長生きし、冒険者は早死にしやすい。
- 死にやすさ: 冒険者としては中〜高(打たれ弱い)。研究職は低いが、実験事故と魔力暴走がある。
- 上位職: 大魔導士、賢者、元素術士、時空術士。

### 2.5 僧侶(神官、治癒術師)

- 役割: 回復と支援。神聖魔法でアンデッドに強い。
- 就く年齢: 教会の孤児院や神学校から10代で見習い、成人で叙階。
- 典型的な人生: 教会での奉仕、冒険者パーティの回復役、従軍神官。出世すれば司教や大司教。
- 死にやすさ: 冒険者としては中。後衛で守られるが、回復役は真っ先に狙われるという戦術の型がある。
- 上位職: 司祭、聖女・聖者、大司教、異端審問官。

### 2.6 盗賊(斥候、シーフ)

- 役割: 罠の解除、鍵開け、偵察、奇襲。
- 就く年齢: 貧民街の子どもが10歳前後から盗みで生き延びて技を覚える、という型が典型。
- 典型的な人生: 冒険者パーティの斥候、盗賊ギルドの構成員、情報屋。足を洗えずに捕まる者も多い。
- 死にやすさ: 高い。罠、先行偵察での遭遇、そして犯罪者としての処刑や私刑。
- 上位職: 暗殺者、怪盗、密偵、忍者(東方系)。

### 2.7 弓使い(狩人、レンジャー)

- 役割: 遠距離攻撃、野外での追跡と生存術。
- 就く年齢: 猟師の家で幼少期から。エルフの定番職。
- 典型的な人生: 猟師、冒険者、軍の弓兵、森林の番人。
- 死にやすさ: 中。距離を取れるので前衛より低いが、野外の事故(滑落、獣)がある。
- 上位職: 狙撃手、森の守護者、魔弓使い。

### 2.8 テイマー(魔物使い)

- 役割: 魔物を従えて戦わせる。本人は弱いことが多い。
- 就く年齢: 動物や魔物と心を通わせる才能が幼少期に現れる。
- 典型的な人生: 冒険者、牧場主、運送業(騎獣や竜の運び屋)、見世物。
- 死にやすさ: 中〜高。従魔が倒されると本人が無防備になる。従魔の暴走で死ぬことも。
- 上位職: 竜使い、魔獣王、召喚士への転向。

### 2.9 召喚士

- 役割: 異界の存在や精霊を呼び出して戦わせる。
- 就く年齢: 魔術学院か秘伝の一族で学ぶ。
- 典型的な人生: 冒険者、宮廷の切り札。強力な召喚は代償(寿命、魔力、体の一部)を要求する型がある。
- 死にやすさ: 中。召喚の失敗、契約違反による死、代償による寿命の短縮。
- 上位職: 大召喚士、精霊王の契約者。

### 2.10 錬金術師

- 役割: 薬品、素材の変換、ポーション、人造生命。
- 就く年齢: 工房に弟子入りするか学院で学ぶ。
- 典型的な人生: 町の薬屋、冒険者向けのポーション職人、宮廷錬金術師。不老不死やホムンクルスに手を出して禁忌に触れる者も。
- 死にやすさ: 低〜中。毒や爆発の実験事故、禁術の研究での処罰。現実の錬金術師には水銀中毒が多かった。
- 上位職: 大錬金術師、賢者の石の探求者。

### 2.11 鍛冶師

- 役割: 武器、防具、道具を作る。ドワーフの定番職。
- 就く年齢: 10〜14歳で親方に弟子入り、20歳前後で職人、30代で親方。
- 典型的な人生: 町や村の鍛冶屋、冒険者向けの武具屋、魔剣の名工。
- 死にやすさ: 低。火傷、目の損傷、肺の病気が慢性的なリスク。
- 上位職: 名工、魔剣鍛冶、付与術師との兼業。

### 2.12 商人

- 役割: 売買、輸送、金貸し。
- 就く年齢: 商家の丁稚や見習いとして10歳前後から。
- 典型的な人生: 店を構える、行商で旅をする、商会に勤めて出世する。成功すれば貴族とも渡り合う。
- 死にやすさ: 定住なら低い。行商は街道の盗賊と魔物で中程度。破産や詐欺による社会的な死もある。
- 上位職: 豪商、商会長、ギルド長、御用商人。

### 2.13 農民

- 役割: 食料の生産。人口の大半。
- 就く年齢: 生まれた時から家の手伝い。
- 典型的な人生: 村で生まれ、村で結婚し、村で死ぬ。徴兵、飢饉、魔物の襲撃、領主の交代で人生が揺れる。
- 死にやすさ: 平時は低い。ただし飢饉と疫病、戦争での略奪の影響を最も受ける。
- 上位職: 豪農、村長、開拓団長。転生ものでは「農業の知識で領地を豊かにする」型の主役になる。

### 2.14 薬師

- 役割: 薬草で病気と怪我を治す。治癒魔法の使えない庶民の医療。
- 就く年齢: 村の薬師や薬屋に弟子入り。
- 典型的な人生: 村の医者として尊敬される。疫病のときは最前線に立つ。
- 死にやすさ: 低〜中。疫病の流行時に感染で死ぬ。魔女として迫害される型もある。
- 上位職: 医師、宮廷薬師、錬金術師への転向。

### 2.15 吟遊詩人

- 役割: 歌、物語、情報の伝達。支援魔法(歌による強化)を使う型も。
- 就く年齢: 旅芸人の一座で育つか、家を飛び出して始める。
- 典型的な人生: 町から町へ旅をし、貴族の宮廷に雇われることも。年を取ると酒場で昔話をする。
- 死にやすさ: 中。旅の危険と、権力者を風刺したことへの報復。
- 上位職: 宮廷楽士、伝説の語り部。

### 2.16 聖騎士

- 役割: 神聖魔法を使う騎士。アンデッドと魔族に強い。
- 就く年齢: 教会の騎士団に入団し、20歳前後で叙任。
- 典型的な人生: 教会騎士団で魔族討伐、異端狩り、巡礼の護衛。
- 死にやすさ: 高い。最も危険な相手(魔族、アンデッドの大群)に送られる。
- 上位職: 聖騎士団長、勇者の随伴者、神の代行者。

### 2.17 暗殺者

- 役割: 要人の暗殺、毒、隠密。
- 就く年齢: 孤児が組織に拾われて幼少期から訓練される、という型が典型。
- 典型的な人生: 組織の駒として働き、使い捨てられるか、足抜けして追われる。
- 死にやすさ: 非常に高い。任務の失敗、組織の口封じ、報復。
- 上位職: 暗殺者ギルドの長、影の宰相。

### 2.18 死霊術師

- 役割: 死者を操る、魂を扱う、呪い。
- 就く年齢: 禁術なので独学か、秘密の師弟関係。
- 典型的な人生: 人目を避けて暮らす。発覚すれば教会に追われる。最終的にリッチ(不死の魔法使い)になることを目指す型もある。
- 死にやすさ: 高い。異端審問、制御を失ったアンデッド、生命力を削る術の代償。
- 上位職: リッチ化、死の王。

### 2.19 傭兵

- 役割: 金で雇われる兵士。
- 就く年齢: 15〜18歳。故郷を追われた者、農家の次男三男。
- 典型的な人生: 戦争から戦争へ渡り歩く。平和になると盗賊に転じる者も多い(中世ヨーロッパの傭兵団の実際の問題)。
- 死にやすさ: 戦時は非常に高い。負け戦の雇い主には報酬も退路もない。
- 上位職: 傭兵団長、騎士への取り立て。

## 3. 職業カタログ(現代・近未来・SF の世界)

異世界の中には、科学が進んだ世界、魔法と科学が混ざった世界、宇宙の世界もある。ランダム人生で世界観を引いたときのために、職業の型を用意しておく。

| 職業 | 世界観 | 役割 | 死亡リスクの性格 |
|---|---|---|---|
| ハッカー | サイバー | 企業や政府のネットワークに侵入 | 中(電脳への逆襲、企業の暗殺) |
| パイロット(戦闘機・人型兵器) | SF、ロボット | 機動兵器の操縦 | 非常に高い(戦時) |
| パイロット(輸送船) | スペースオペラ | 宇宙の運送 | 中(事故、海賊) |
| 傭兵・私兵 | サイバー、SF | 企業の私兵、紛争地の請負 | 高 |
| 賞金稼ぎ | SF、西部劇風 | 指名手配犯を追う | 高 |
| 企業勤め | サイバー | 巨大企業の社員 | 低(ただし過労と粛清) |
| 改造医(闇医者) | サイバー | サイボーグ手術、闇の医療 | 中 |
| 探索者(廃墟漁り) | ポストアポカリプス | 遺跡から物資を回収 | 非常に高い |
| 農場主(水耕・開拓惑星) | SF、荒野 | 食料生産 | 中(襲撃、環境) |
| 研究者 | 全般 | 科学研究、魔法と科学の境界 | 低(実験事故) |
| 宇宙軍兵士 | スペースオペラ | 艦隊戦、惑星降下 | 戦時は非常に高い |
| 採掘労働者(小惑星) | SF | 資源採掘 | 高(減圧、放射線) |
| アイドル・配信者 | 現代、サイバー | 人気商売 | 低(ストーカー、過労) |
| 探偵 | 現代、サイバー | 調査 | 中 |

## 4. 上位職への転職

### 4.1 転職の型

| 型 | 内容 | 例 |
|---|---|---|
| 一本道の上位化 | 経験を積むと同じ系統の上位職になる | 戦士 → 重戦士 → 将軍 |
| 二職の融合 | 二つの職業を極めると複合職になる | 戦士 + 魔法使い → 魔法剣士 |
| 選択式の分岐 | 一定の段階で道を選ぶ | 僧侶 → 司祭(聖)か異端審問官(武) |
| 隠し職 | 条件を満たした者だけがなれる | 盗賊が一定数のアンデッドを倒す → 墓守 |
| 称号・祝福 | 偉業で神や国から与えられる | 魔王討伐 → 勇者、竜殺し |
| 闇落ち | 禁忌や絶望で別系統に変わる | 聖騎士 → 暗黒騎士、魔法使い → 死霊術師 |

JRPG の転職システムでは、特定の施設(神殿)で一定の熟練度を満たせば職業を変えられ、前の職業の技を一部引き継げる、という形が多い。LitRPG では、レベルとステータスの条件を満たしたときにシステムのメッセージが出て選択肢が提示される形が定番。

### 4.2 代表的な転職の木

```
戦士 ─┬─ 剣士 ──── 剣聖
      ├─ 騎士 ──┬─ 聖騎士(+僧侶の素養)
      │         └─ 騎士団長
      ├─ 狂戦士
      └─ 魔法剣士(+魔法使い)

魔法使い ─┬─ 大魔導士 ── 賢者(+僧侶)
          ├─ 元素術士(属性特化)
          ├─ 召喚士
          ├─ 付与術師
          └─ 死霊術師(禁術への転落)

僧侶 ─┬─ 司祭 ── 司教 ── 大司教
      ├─ 聖女・聖者(加護による)
      ├─ 異端審問官
      └─ 武僧(+戦士)

盗賊 ─┬─ 暗殺者
      ├─ 怪盗
      ├─ 密偵
      └─ 斥候隊長

弓使い ─┬─ 狙撃手
        └─ 森の守護者

生活職: 見習い ── 職人 ── 親方 ── 名工・ギルド長
```

### 4.3 転職の時期の目安

現実の徒弟制度(見習い7年前後、職人として遍歴の旅、親方試験)を下敷きにすると、生産職の昇格は次のような時間で進む。

| 段階 | 年齢の目安(人間) | 必要年数 |
|---|---|---|
| 見習い・弟子 | 10〜14歳 | 5〜7年 |
| 職人・一人前 | 17〜21歳 | — |
| 熟練 | 25〜30歳 | 職人として5〜10年 |
| 親方・上位職 | 30〜40歳 | 親方試験か実績 |
| 名工・伝説 | 50歳以降 | ごく一部 |

戦闘職の上位職は、年数よりも「生き延びて実績を積んだか」で決まる。冒険者の上位職への到達率を低くしておけば、生存者バイアスによって上位職ほど強者ばかりになる。長命種は同じ段階を何倍もの年数をかけて進むので、「100年修行したエルフの剣聖」が自然に出てくる。

## 5. 魔法体系の型

### 5.1 属性

ジャンルでいちばん多いのは、火・水・風・土の四大元素に、光・闇を足した六属性。そこに無属性、雷、氷、時空、聖、死などの派生や上位属性が加わる。

| 属性 | 典型的な効果 | 対になる属性 | 強い相手 |
|---|---|---|---|
| 火 | 攻撃、燃焼、鍛冶 | 水 | 氷、植物、アンデッド |
| 水 | 治癒の補助、浄化、生活 | 火 | 火の魔物 |
| 風 | 速度、飛行、索敵 | 土 | 飛ぶ敵 |
| 土 | 防御、建築、農業 | 風 | 地上の大型 |
| 光 | 治癒、浄化、結界 | 闇 | アンデッド、魔族 |
| 闇 | 呪い、隠密、精神操作 | 光 | 人間、天使 |
| 雷 | 高威力の攻撃 | 土(地面に逃げる) | 水の魔物、機械 |
| 氷 | 拘束、凍結 | 火 | 火の魔物 |
| 時空 | 転移、収納、加速 | — | すべて(希少) |
| 無属性 | 身体強化、魔力弾 | — | — |

属性の適性は生まれつき決まり、1〜2属性持ちが普通、3属性以上は天才、全属性は伝説、という希少度の型が多い。闇属性が生まれつき出ると差別される、という社会設定もよく使われる。

### 5.2 発動の方式

| 方式 | 内容 | ゲーム上の性格 |
|---|---|---|
| 詠唱 | 呪文を唱えて発動 | 時間がかかる、黙らされると使えない、言語や教育が必要 |
| 短縮詠唱 | 呪文の一部や名前だけで発動 | 熟練者の証 |
| 無詠唱 | 想像だけで発動 | 天才や転生者の特権として描かれやすい |
| 魔法陣 | 地面や紙に陣を描く | 準備が必要だが大規模、儀式や結界向き |
| 魔道具 | 道具に魔法を込めて誰でも使える | 魔力がない人でも使える、文明の基盤 |
| 契約 | 精霊や悪魔と契約して力を借りる | 代償、契約相手の機嫌 |
| 祈り | 神に祈って奇跡を起こす | 信仰心、教会との関係が条件 |
| 技能(スキル) | システムが与える技を名前で発動 | LitRPG 型、レベルで習得 |

転生ものでは「前世の科学知識で魔法の原理を理解すると、無詠唱で威力が上がる」という型が非常に多い。

### 5.3 魔力量

- 生まれつきの量が決まっていて、成長期に訓練すると伸びる、という型が多い。幼少期に魔力を使い切る訓練を繰り返すと量が増える、という型も定番。
- 魔力を使い切ると気絶、さらに無理をすると命や寿命を削る。
- 魔力の多さが身分や結婚相手の価値を決める社会(貴族は魔力が多い)もよく描かれる。
- 魔力が全くない者は差別される、または逆に魔法が効かない特異体質として扱われる。

### 5.4 魔法の系統

| 系統 | 力の源 | 担い手 | 社会での位置 |
|---|---|---|---|
| 元素魔法(魔術) | 自分の魔力と理論 | 魔法使い、学者 | 学院で学ぶ学問、国家の軍事力 |
| 精霊魔法 | 精霊との交感と契約 | エルフ、巫女、自然崇拝の民 | 森の民の秘儀、人間には難しい |
| 神聖魔法 | 神への信仰 | 僧侶、聖騎士、聖女 | 教会が独占、治癒の供給源 |
| 呪術・闇魔法 | 呪い、負の感情、悪魔 | 呪術師、魔族 | 忌避、違法 |
| 死霊術 | 魂と死体 | 死霊術師 | 禁術 |
| 付与魔法 | 物体に魔力を込める | 付与術師、鍛冶師 | 産業、魔道具の基盤 |
| 召喚術 | 異界の存在 | 召喚士 | 戦力、危険視 |
| 時空魔法 | 時間と空間 | 希少な天才 | 国家の秘密、伝説 |
| 錬金術 | 物質の変換 | 錬金術師 | 科学に近い、薬の供給源 |
| 身体強化・気 | 体内の気や魔力 | 戦士、武僧 | 戦闘職の基礎技術 |

### 5.5 禁術

禁術はほぼどの世界にもある。禁じられる理由の型は次のとおり。

- 生命の操作: 死者蘇生、人造生命、不老不死。神の領域への侵犯とされる。
- 魂の操作: 精神支配、魂の抽出、他人の体を奪う。
- 代償が大きすぎる: 寿命、生贄、都市一つ分の魔力。
- 世界への害: 大規模破壊、異界の扉、時間の改変。
- 政治的理由: 教会や国が独占したい力を、他者に使わせないために禁じる。

ゲームでは、禁術に手を出すと能力は上がるが、異端審問や代償による死亡のリスクが上乗せされる、という形にするとよい。

### 5.6 科学で説明できる魔法

転生ものでは、魔法を科学で解釈し直すのが定番の楽しみになっている。

- 火魔法は酸素の供給と温度の制御で、青い炎のほうが強い。
- 水魔法は空気中の水分の凝結。
- 氷魔法は分子運動の停止(熱を奪う)。
- 雷魔法は電荷の分離。
- 治癒魔法は細胞分裂の促進なので、解剖学を知る者のほうが治せる範囲が広い。逆に、知識なしに使うと骨が曲がってくっつくなどの失敗が起きる。
- 回復魔法を使いすぎると細胞分裂の回数を消費して寿命が縮む、という設定も時々ある。

ゲームでは、転生者や科学の知識を持つ者に魔法の効率の係数をかける程度で表現できる。

### 5.7 魔法が社会をどう変えるか

魔法がどれくらい普及しているかで、世界の死亡率と経済が大きく変わる。

| 普及度 | 特徴 | 死亡率への影響 |
|---|---|---|
| 希少(魔法使いは数千人に1人) | 魔法は軍事と権力者のもの | 庶民の医療は薬草だけ。死亡率は前近代そのもの |
| 限定(数百人に1人) | 町に一人は治癒師がいる、教会が独占 | 金持ちと教会の信者は助かる。格差が死亡率に出る |
| 普及(数十人に1人) | 生活魔法(火起こし、水、照明)が日常 | 衛生が改善、感染症が減る。乳幼児死亡が大きく下がる |
| 遍在(誰でも使える) | 魔道具が文明の基盤 | 近代に近い死亡率。死因が戦争と魔物に偏る |

## 6. 治癒・ポーション・蘇生と死亡率

### 6.1 何が死亡率を下げるか

前近代の人間の死因は、感染症(疫病、下痢、肺炎)、乳幼児期の病気、出産、外傷の感染、飢饉、戦争が大部分を占めていた。外傷の死亡の多くは、受傷直後よりも、その後の感染(破傷風、敗血症、壊疽)で起きた。治癒魔法やポーションは、この「後で死ぬ」部分を大きく減らす。

| 手段 | 効く範囲 | 効かない範囲 | 入手性 |
|---|---|---|---|
| 薬草・薬師 | 軽い病気、軽傷 | 重傷、疫病の重症 | 村にもある |
| 下級ポーション | 切り傷、打撲、出血の停止 | 骨折、欠損、病気 | 冒険者が常備、安い |
| 中級ポーション | 骨折、深い傷 | 欠損、毒の一部 | 冒険者の稼ぎ数日分 |
| 上級ポーション・エリクサー | 欠損の再生、瀕死からの回復 | 死亡 | 非常に高価、希少 |
| 解毒薬・解毒魔法 | 毒 | — | 毒の種類による |
| 治癒魔法(初級) | 外傷 | 病気、欠損 | 教会、冒険者の回復役 |
| 治癒魔法(上級) | 重傷、欠損、病気の一部 | 寿命、呪い | 高位の神官、寄付が必要 |
| 浄化魔法 | 呪い、アンデッド化、感染症 | — | 教会 |
| 蘇生魔法 | 死亡直後の復活 | 時間が経った死、老衰 | 世界による(後述) |

### 6.2 蘇生の有無の型

| 型 | 内容 | ゲームでの扱い |
|---|---|---|
| 蘇生なし | 死は絶対 | もっとも緊張感がある。なろう系の主流 |
| 伝説の蘇生 | 聖女や秘宝でのみ、一生に一度 | 物語の大事件として扱う |
| 高価な蘇生 | 教会に莫大な寄付をすれば蘇生できる | 金持ちと上位冒険者だけが死から戻れる |
| 条件付き蘇生 | 死後数分以内、遺体が損傷していない場合だけ | 即死と遺体の喪失が本当の死になる |
| 日常的な蘇生 | ゲーム的に何度でも戻れる(JRPG の教会) | 死の意味が薄い。ランダム人生には向かない |
| 代償付き蘇生 | 生き返るたびに何かを失う(寿命、記憶、能力) | 蘇生回数に上限、人生が変化する |

ランダム人生ゲームでは「蘇生なし」か「条件付き・高価な蘇生」が向いている。死が人生の終わりでなければ、一生のシミュレーションとして成り立たない。

### 6.3 死亡率への効き方の目安

治癒の普及度を世界の係数として持ち、外傷死と感染症死を別々に減らすのが扱いやすい。

| 世界の治癒水準 | 外傷による死(人間の前近代比) | 感染症・疫病による死 | 出産による母体の死 | 乳幼児死亡 |
|---|---|---|---|---|
| なし(薬草のみ) | 1.0 | 1.0 | 1.0(1回あたり1〜2%) | 1.0 |
| 教会が治癒を独占 | 0.7(庶民0.9、貴族0.3) | 0.8 | 0.7 | 0.8 |
| ポーションが流通 | 0.5 | 0.9(ポーションは病気に弱い) | 0.6 | 0.8 |
| 治癒と浄化が普及 | 0.3 | 0.4 | 0.3 | 0.4 |
| 魔道具文明 | 0.2 | 0.2 | 0.15 | 0.2 |

冒険者の場合、外傷の大半は「その場で即死」と「後で死ぬ」に分かれる。ポーションや回復役は後者だけを救う。戦闘での即死の割合をおおよそ3〜4割とすると、どれだけ治癒が充実しても冒険者の死亡率は半分程度までしか下がらない、という形になる。これは「回復役がいても死ぬときは死ぬ」というジャンルの感覚とも合う。

### 6.4 冒険者パーティに回復役がいるかどうか

| パーティの状態 | 冒険者の年間死亡率への倍率 |
|---|---|
| 回復手段なし(ソロ、ポーションなし) | 1.5 |
| ポーションのみ | 1.0(基準) |
| 回復役が1人いる | 0.7 |
| 高位の回復役 + 上級ポーション | 0.5 |
| 蘇生可能な神官が同行 | 0.3(蘇生の失敗分だけ死ぬ) |

## 7. 冒険者ギルド

### 7.1 ギルドの役割

冒険者ギルドは、なろう系の世界でほぼ標準装備になった組織で、現実の中世の同業組合(ギルド)と、現代の職業紹介所や人材派遣会社を混ぜたような存在として描かれる。

- 依頼の仲介: 依頼人から仕事を受け、冒険者に紹介し、仲介料を取る。
- 身分証明: 冒険者カード(ギルド証)が国境を越える身分証になる。
- 等級管理: 冒険者の実力をランクで管理し、身の丈を超えた依頼を受けさせない。
- 素材の買い取り: 魔物の素材や魔石を買い取り、商会や職人に流す。
- 緊急時の動員: 魔物の大量発生や災害時に、冒険者を強制的に招集する。
- 中立性: 国家から独立した組織として、戦争には参加しない、という建前が多い。

### 7.2 ランクの型

ランクの付け方には、アルファベット型と金属型の二つが特に多い。

| アルファベット型 | 金属型 | 実力の目安 | 人数比の目安 | 主な依頼 |
|---|---|---|---|---|
| F | 木・石 | 登録直後の見習い | 30% | 薬草採取、町の雑用、どぶさらい |
| E | 鉄 | 駆け出し | 25% | 小型の魔物の駆除(スライム、ゴブリン数匹) |
| D | 銅 | 一人前の入り口 | 20% | 隊商の護衛、ゴブリンの巣 |
| C | 銀 | 一人前、ベテラン | 15% | 中型の魔物、ダンジョンの中層 |
| B | 金 | 地方の有力者 | 7% | 大型の魔物、盗賊団の討伐 |
| A | 白金・ミスリル | 国の切り札 | 2.5% | 竜種、災害級の魔物 |
| S | アダマンタイト・オリハルコン | 英雄、伝説 | 0.5%未満 | 国難、魔王軍の幹部 |

人数比はピラミッドで、ほとんどの冒険者は C 以下で生涯を終える。現実の多くの職業ヒエラルキーと同じで、上の層は生存と才能の両方で選ばれる。

### 7.3 依頼の種類

| 種類 | 内容 | 危険度 | 報酬 |
|---|---|---|---|
| 採取 | 薬草、鉱石、魔物の素材 | 低 | 低 |
| 雑用 | 町の手伝い、配達、どぶさらい | ほぼなし | 非常に低 |
| 討伐 | 指定の魔物を倒す | 中〜高 | 中 |
| 護衛 | 隊商や要人の旅の護衛 | 中(盗賊、魔物) | 中、日数で増える |
| 調査 | 異変の原因、遺跡の探索 | 中〜高(不明な危険) | 中 |
| ダンジョン攻略 | 迷宮の探索、魔石と宝 | 高 | 高(当たり外れ) |
| 緊急依頼 | 魔物の氾濫、大災害 | 非常に高 | 高、強制参加 |
| 指名依頼 | 貴族や国からの個人指名 | さまざま | 高 |
| 賞金首 | 指名手配の盗賊や魔物 | 高 | 高 |

### 7.4 昇格の仕組み

- 依頼の達成数とポイントでランクが上がる。一定ランク以上は昇格試験(実技、筆記、面接)がある。
- 上位ランクには推薦や実績(大物の討伐)が必要。
- ランクが上がると受けられる依頼が増え、報酬も上がるが、死亡率の高い依頼を受けることになる。
- 失敗が続くと降格、規約違反は除名。
- パーティにもランクがあり、個人より高いランクの依頼をパーティで受けられる世界もある。

ランク別に1年あたりの昇格確率を置くと、次のような感覚になる(才能と運の補正前)。

| 現在のランク | 1年で昇格する確率 | 備考 |
|---|---|---|
| F → E | 70% | ほぼ誰でも上がる |
| E → D | 40% | ここで脱落(引退、死亡)が多い |
| D → C | 20% | 一人前の壁 |
| C → B | 6% | 才能か大きな実績が必要 |
| B → A | 1.5% | 地方で数人 |
| A → S | 0.2% | 一世代に数人 |

### 7.5 引退

| 引退のきっかけ | 年齢・時期の目安 | 引退後の典型 |
|---|---|---|
| 体力の衰え | 人間で35〜45歳 | ギルド職員、教官、酒場、宿屋 |
| 大怪我(欠損、後遺症) | いつでも | 物乞い、実家に戻る、治癒魔法があれば復帰 |
| 結婚・出産 | 20〜30代 | 家業、農業 |
| 稼いだ金で店を開く | 30代 | 商人、宿屋の主 |
| 仲間の死 | いつでも | 心の傷で引退、別の職業へ |
| 貴族への取り立て | 上位ランク | 騎士、領主 |
| 生涯現役 | 一部の上位者 | 前線で死ぬか、伝説になる |

現実の兵士や運動選手の現役期間を参考にすると、人間の前衛職の現役のピークは20代後半から30代前半で、40代での前線は珍しい。長命種はこのピークが老化速度に比例して長く続く(エルフの現役期間は数百年)。

### 7.6 冒険者の典型的な死に方

ジャンルの作品を通して繰り返し描かれる冒険者の死亡の型を、頻度の高い順にまとめる。

| 死に方 | 起きやすいランク | 内容 |
|---|---|---|
| 駆け出しの慢心 | F〜E | 弱い魔物と侮ってゴブリンの巣に入り、数の暴力で全滅 |
| 想定外の上位種 | E〜C | 簡単な依頼の現場に、本来いないはずの強い魔物がいる |
| 罠 | D〜B | ダンジョンの落とし穴、毒矢、転移罠で分断 |
| 消耗と撤退の失敗 | C〜B | 深く潜りすぎて魔力とポーションが尽き、帰り道で死ぬ |
| 仲間の裏切り | すべて | 報酬の独り占め、囮にされる、置き去り |
| 盗賊・冒険者狩り | E〜C | 依頼帰りの冒険者を狙う人間の盗賊 |
| 感染と毒 | すべて | 傷口の化膿、解毒が間に合わない毒 |
| 魔物の氾濫・緊急依頼 | すべて(強制参加) | 大量発生した魔物の波に飲まれる |
| 大物への挑戦 | B〜S | 竜や魔王軍幹部との戦いで戦死 |
| 遭難・環境 | すべて | 雪山、砂漠、迷宮での迷子、飢えと渇き |
| 依頼人の嘘 | D〜B | 依頼内容が偽りで、実際ははるかに危険 |

ランダム人生では、死因を職業とランクの組み合わせでこの表から引くと、一生の記録に具体性が出る。

## 8. その他の組織

### 8.1 騎士団

- 種類: 国王直属の騎士団、地方領主の騎士団、教会の騎士団(聖騎士団)、特定の任務の騎士団(竜騎士団、魔物討伐団)。
- 入団: 貴族の子弟が中心。平民は実績や武功で取り立てられる例外として描かれることが多い。
- 階級: 見習い(小姓、従騎士) → 騎士 → 隊長 → 副団長 → 団長。
- 人生の節目: 叙任、初陣、武功による爵位、戦死、負傷による退団、領地の拝領。
- 死亡率: 戦時と平時で大きく変わる。中世ヨーロッパの騎士は身代金のために捕らえられることが多く、戦死率は歩兵より低かったと言われる。ただし大敗した戦いでは騎士の大量戦死も起きた。

### 8.2 魔術学院

- 入学: 魔力の適性検査に合格した者。貴族の子弟が多いが、特待生の平民枠がある型が定番(転生した主人公が平民の天才として入学し、貴族から嫌がらせを受ける)。
- 入学年齢: 12〜15歳、在籍3〜6年。
- 学年と階級: 学年に加えて成績による序列。卒業後に魔術師の位階(見習い、正魔術師、上級、導師)が与えられる。
- 卒業後の進路: 宮廷魔術師、軍の魔術兵、研究者として学院に残る、冒険者、魔道具の職人、貴族の家庭教師。
- 人生の節目: 入学試験、決闘や対抗戦、卒業研究、禁書庫への侵入、学院の派閥争い。
- 死亡率: 在学中は低い。ただし実験事故、魔力暴走、学院のダンジョン実習での事故がある。

### 8.3 教会

- 構造: 教皇(大神官)を頂点に、枢機卿、大司教、司教、司祭、助祭、修道士・修道女、信徒。
- 役割: 信仰、治癒魔法の独占的な供給、孤児院、教育、冠婚葬祭、戸籍の管理(洗礼と埋葬の記録)。
- 権力: 王権と並ぶか、王権を超える。聖女の認定、勇者の選定、異端審問、破門の権限。
- 人生の節目: 洗礼、成人の儀式(天職の授与)、結婚、葬儀。聖職者になる人には叙階、出世、異端の嫌疑。
- 影の面: 治癒の寄付金の高さ、腐敗、他種族や闇属性への差別、異端狩り。
- 死亡率への影響: 治癒の供給源なので、教会との関係(寄付できるか、信者か、異端扱いされていないか)が個人の外傷死と疫病死を左右する。

### 8.4 商会

- 構造: 会頭(商会長)と一族、番頭、手代、丁稚。日本の商家の階級と、ヨーロッパの商社の両方の型がある。
- 役割: 交易、金融(両替、貸付、為替)、隊商、商業ギルドでの価格調整。
- 商業ギルド: 商人の同業組合。営業許可、価格のとりきめ、紛争の仲裁。冒険者ギルドとは素材の売買で深くつながる。
- 人生の節目: 丁稚奉公、暖簾分け(独立)、大口の取引、破産、貴族との婚姻、御用商人の指定。
- 死亡率: 本人は低い。隊商に同行する場合は街道の危険を受ける。
- 転生ものの定番: 前世の知識(簿記、新しい料理、印刷、石鹸)で商会を大きくする。

### 8.5 盗賊ギルド・裏社会

- 構造: 頭領、幹部、構成員、使い走り。縄張り、上納金、掟。
- 役割: 窃盗、密輸、情報、裏の仕事の仲介。暗殺者ギルドが独立している場合も。
- 人生の節目: 入会の試練、初仕事、昇進、裏切り、足抜け(多くは命がけ)。
- 死亡率: 高い。抗争、処刑、口封じ。

### 8.6 軍隊

- 構造: 将軍、指揮官、士官、兵士。徴兵された農民、常備兵、傭兵、魔術兵、騎兵。
- 人生の節目: 徴兵、初陣、昇進、負傷除隊、戦死、退役。
- 死亡率: 戦時に跳ね上がる。前近代の軍では、戦闘よりも行軍中や野営地での病気による死が多かった。

### 8.7 王宮・貴族

- 階級: 王、公爵、侯爵、伯爵、子爵、男爵、騎士爵。
- 人生の節目: 婚約(政略結婚)、社交界デビュー、家督の相続、政争、暗殺、没落、追放。なろう系では婚約破棄と追放が人生の一大転機になる型が定番。
- 死亡率: 栄養と治癒の面では恵まれるが、政争と暗殺、戦争の指揮官としての死がある。
