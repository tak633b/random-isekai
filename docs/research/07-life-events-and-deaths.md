# 07 人生の出来事と死 — 年齢ごとのイベント型と死に方の型

異世界での一生をランダムに組み立てるための素材集。前半は年齢ごとの典型イベント(約240件)、後半は死に方の型(約100件)と、現実の中世・近世ヨーロッパの死因構成。最後に、これをシミュレーションの確率表にする方法を書く。

イベントはジャンルで繰り返し使われてきた一般的な型で、特定作品の設定は使っていない。各項目は「短い型」なので、実装時は世界観・身分・職業の条件をつけて抽選する。

---

## 1. 年齢区分

| 区分 | 年齢の目安 | 性格 |
|---|---|---|
| 誕生・乳児期 | 0〜2歳 | 生き残れるかどうか。転生の自覚が来ることもある |
| 幼少期 | 3〜9歳 | 能力判明、家庭環境、最初の事件 |
| 少年期 | 10〜15歳 | 学院・徒弟・登録・婚約、世界との接触 |
| 青年期 | 16〜29歳 | 冒険・戦争・恋愛・独立。死亡リスクの山 |
| 壮年期 | 30〜44歳 | 地位の確立、家族、領地、名声 |
| 中年期 | 45〜59歳 | 後進、管理職、衰え、政治 |
| 老年期 | 60歳以上 | 隠居、伝説、看取り、最期 |

長命種(エルフ・ドワーフ・竜人など)はこの区分を伸ばして使う。エルフなら「青年期」が100年続く、というように。

## 3. 死に方の型

各項目に頻度の目安をつける。「よくある」「ふつう」「まれ」「ごくまれ」の4段階。ファンタジー中世を基準にしている。

### 3.1 病と身体(全世界で最大の死因群)

1. 乳幼児期の病(熱、下痢、咳) — よくある
2. 死産・生後数日の衰弱 — よくある
3. 疫病(黒死病型の大流行) — ふつう(流行年はよくある)
4. 結核に相当する消耗病 — よくある
5. 熱病 — よくある
6. 胃腸の病 — よくある
7. 肺の病 — よくある
8. 天然痘型の発疹病 — ふつう
9. 傷の化膿・破傷風 — ふつう
10. 出産(本人が母として) — ふつう
11. 出産後の産褥熱 — ふつう
12. 心臓の発作 — ふつう(中年以降)
13. 卒中 — ふつう(中年以降)
14. 腫瘍・不治の病 — まれ
15. 老衰 — ふつう(長生きできれば)
16. 魔力欠乏症 — まれ(魔力依存体質の世界)
17. 瘴気による病 — ふつう(魔王復活期・汚染地帯)
18. 魔物由来の奇病・寄生 — まれ
19. 呪病(呪いによる衰弱) — まれ

## 5. 現実の歴史の死因構成(参照点)

異世界の死因比率を決めるとき、現実の中世・近世ヨーロッパがどうだったかを基準にすると、手触りが出る。ただし過去の死因統計は不完全で、分類も現代と違う。以下は「おおよその桁と順位」をつかむための材料として使う。

### 5.1 中世イングランド(1200〜1500年)の健康負担

Robb ほか(International Journal of Paleopathology, 2021)は、文書・考古学・古病理学の証拠を組み合わせ、10万人の中世イングランド人口を想定して病気ごとの負担(失われた生存年数と障害年数)を推定した。その上位15項目は次の順だった。

1. 乳幼児の死(原因はさまざま)
2. 結核
3. 熱病
4. ウイルス性の肺の感染症
5. 下痢・胃腸の感染症
6. ハンセン病
7. 社会的不平等
8. 脳卒中
9. 骨折
10. マラリア
11. ペスト
12. 出産
13. くる病
14. がん
15. 精神疾患

同研究によれば、中世後期全体で見ると、乳幼児期の病で死ぬリスクはペストで死ぬリスクの15〜20倍、主要な6種ほどの常在する感染症のどれかで死ぬリスクはペストの4〜8倍だった。暴力はこの上位15に入っていない。

出典: Medievalists.net による紹介記事 https://www.medievalists.net/2021/12/health-problem-middle-ages/ (原論文 Robb, Cessford, Dittmar, Inskip, Mitchell, "The greatest health problem of the Middle Ages? Estimating the burden of disease in medieval England")

ゲームへの含意: 「よくある死」の筆頭は戦いでも魔物でもなく、子どもの病と感染症。ここを外すと異世界の生活感が薄くなる。逆に、冒険者という特殊な職業がそれをひっくり返している、という構図が描ける。

### 5.2 乳幼児の死

- 17世紀ロンドンの死亡表を分析したジョン・グラント(1662年)は、ロンドンの全死亡のうち約36%が6歳未満の子どもだったと推定した。出生100人のうち約36人が6歳までに死ぬ、という計算でもある。
  出典: https://en.wikipedia.org/wiki/John_Graunt / https://bigthink.com/the-past/the-dark-brilliance-of-john-graunt-father-of-modern-statistics/
- 近世イングランドの乳児死亡率について、Davenport(2014)のレビューは、1740年代のロンドンで出生1000あたり400〜450に達した可能性があり、1820年代には全国平均並みの約160になったと述べている。
  出典: https://research.ncl.ac.uk/pauperlives/documents/DavenportCambridgeanniversarypaper16September2014.pdf
- 教区簿冊にもとづく推定は埋葬の記録漏れで低く出ることがある(Razzell 2007)。
  出典: https://www.Gwern.net/doc/history/2007-razzell.pdf

ゲームへの含意: 生まれた子の 15〜30% が1歳までに、30〜40% が成人前に死ぬ、という水準が「現実の前近代」。転生主人公は物語の都合で生き残るとしても、兄弟姉妹・自分の子・村の子どもには、この率をそのまま当てると重みが出る。

### 5.3 出産による母の死

- Schofield(1986)は1540〜1837年のイングランドの村の家族復元データから最初の妊産婦死亡率の推計を出した。Alter(2025)はこれを再検討し、1650〜1800年の前工業期イングランドで出生1000あたり約10(1回の出産で約1%)と報告している。
  出典: https://api.isr.umich.edu/projects/maternal-mortality/
- ケンブリッジ人口史グループのブログでは、17世紀半ばのピークで出生1万あたり170(1.7%)、前工業期の平均で120(1.2%)としている。
  出典: https://www.campop.geog.cam.ac.uk/blog/2024/09/19/childbirth-in-the-past/

ゲームへの含意: 1回の出産で約1〜1.7%。5〜6回出産する女性なら、生涯で数%から1割近くが出産で死ぬ計算になる(この累積は単純計算で、上記出典の値ではない)。

### 5.4 感染症と疫病

- 1660〜1679年のロンドンでは、感染症が総死亡率の66.6%を占めたとする分析がある(しかも一部の感染症を分類から外した値)。
  出典: https://www.milbank.org/wp-content/uploads/mq/volume-14/issue-04/14-4-Changes-in-the-Death-Rate-Since-the-Seventeenth-Century.pdf
- 1665年ロンドン大疫病の年には、約9万7千の死亡のうちペストが約6万8千6百とされる。平常年とは別の、流行年の値として扱う。
  出典: https://publicdomainreview.org/collection/londons-dreadful-visitation-bills-of-mortality
- 黒死病(1347〜1352年)による欧州の人口減少は、推計によって30〜60%と幅がある。Jedwab らの2019年の研究は西欧で平均約39%と見積もった。
  出典: https://historycrunch.com/how-many-people-died-in-the-black-death/
- 死亡表の「ひきつけ(Convulsions)」は乳児のさまざまな病をまとめた分類だった。分類そのものが当時の医学の限界を反映している。
  出典: https://worldhistorycommons.org/node/95

### 5.5 飢饉

- 1315〜1317年の大飢饉では、北欧(北部ヨーロッパ)の人口の5〜12%が死んだと推定される。死者の多くは飢えそのものより、衰弱した体を襲った病によるものだった。
  出典: https://en.wikipedia.org/wiki/Great_Famine_of_1315%E2%80%931317

### 5.6 暴力

- Eisner の殺人率データによれば、13〜14世紀の西欧では殺人率が年間10万人あたり10を超え、イタリアでは70に達した。イングランドは1300〜1349年で約21、15世紀後半で約24。14世紀フィレンツェでは150という推定もある。現代の西欧は1前後。
  出典: https://ourworldindata.org/data-insights/homicide-rates-have-declined-dramatically-over-the-centuries / https://humanprogress.org/trends/global-murder-rate-is-falling/ / https://www.vrc.crim.cam.ac.uk/system/files/documents/manuel-eisner-historical-trends-in-violence.pdf
- 同じく Eisner の研究では、西暦600〜1800年の欧州の君主1513人について、あらゆる種類の暴力による死が全死因の約22%を占めた。
  出典: https://ojp.gov/ncjrs/virtual-library/abstracts/killings-kings-patterns-regicide-europe-ad-600-1800
- 19世紀末スコットランドのある地方報告では「暴力(事故を含む外因)」が全死亡の4.6%だった。前近代の平民における外因死の参考になる。
  出典: https://scotlandsplaces.gov.uk/digital-volumes/official-reports/medical-officer-health-reports/medical-officer-health-reports-1891-lanarkshire/17

計算の目安: 殺人率が10万人あたり20〜40で、全体の粗死亡率が1000人あたり25〜30(近世イングランドの値。Wrigley と Schofield の再構成による。出典 https://alanmacfarlane.com/savage/A-MORT.PDF)なら、殺人は全死亡の約1%前後になる。戦争・事故を加えても、平民の外因死は全体の数%から1割程度と見るのが妥当。王族では2割を超える。

### 5.7 平常年の前近代ヨーロッパの死因構成(ゲーム用の丸めた推定)

上の出典から、平常年(大疫病・大飢饉・大戦争のない年)の平民の死因を、ゲーム用に丸めた。これは単一の文献の数値ではなく、複数の出典を組み合わせた設計者の推定である。

| 死因群 | 全死亡に占める割合(目安) | 根拠 |
|---|---|---|
| 乳幼児の死(5歳未満、原因を問わず) | 30〜40% | グラントの36%、乳児死亡率160〜450 |
| 成人・年長児の感染症(結核・熱病・胃腸・肺) | 30〜40% | 感染症66.6%(乳幼児分と重複あり)、Robb らの順位 |
| 出産(母) | 2〜4% | 出生あたり1〜1.7% × 出生数 |
| 慢性病・老衰(卒中・心臓・がん・老い) | 10〜20% | Robb らの順位、近世の高齢層 |
| 事故 | 3〜5% | 地方報告の外因4.6% |
| 暴力(殺人・決闘・私刑) | 0.5〜2% | 殺人率と粗死亡率の比 |
| 戦争 | 0〜5%(平時ほぼ0、戦時は急増) | 地域・時期による |
| 飢饉 | 平常年はほぼ0、凶作年は人口の5〜12% | 大飢饉の推計 |

流行年の補正: 黒死病級の大流行は、その数年間だけで人口の3〜6割を奪う。1665年ロンドンのように、流行年には一つの病が死亡の7割を占めることもある。

## 6. シミュレーションへの使い方

### 6.1 列挙値

イベントと死因は、カテゴリ・年齢帯・条件・重みの4つで持つ。

```
EventCategory = birth | awakening | appraisal | family | education | adventure
              | dungeon | war | romance | marriage | children | rank | nobility
              | commerce | church | slavery | exile | revenge | mentor | aging | legend
              | sf_corp | sf_space | sf_body | ability

DeathCategory = infant | disease | plague | childbirth | famine | exposure
              | accident | monster | dragon | dungeon | war | violence
              | assassination | poison | execution | slavery | magic_cost
              | curse | hero_slain | demonlord_slain | sacrifice | old_age
              | sf_vacuum | sf_radiation | sf_machine | sf_cyber | sf_ai | vanished

Frequency   = common(重み 10) | normal(重み 3) | rare(重み 1) | very_rare(重み 0.2)
```

### 6.2 年ごとの死亡判定

毎年、年齢・身分・職業・世界状態から基礎死亡確率を出し、死亡したら死因を重みで抽選する二段方式がわかりやすい。

1段目の年あたり死亡確率の目安(ファンタジー中世の平民):

| 年齢 | 年あたり死亡確率 | 備考 |
|---|---|---|
| 0歳 | 15〜25% | 乳児期。現実の前近代の水準 |
| 1〜4歳 | 3〜5% | 幼児期の病 |
| 5〜14歳 | 0.5〜1% | 一生で最も安全な時期 |
| 15〜29歳 | 1〜1.5% | 女性は出産、男性は暴力・戦争が上乗せ |
| 30〜44歳 | 1.5〜2% | |
| 45〜59歳 | 2〜4% | 慢性病の増加 |
| 60〜69歳 | 4〜7% | |
| 70〜79歳 | 8〜15% | |
| 80歳以上 | 15〜30% | |

ここに職業倍率を掛ける。冒険者は15〜40歳の間、全体で 2〜4倍(新人の最初の3年はさらに倍)。兵士は戦時に 3〜6倍。回復魔法が普及した世界や、主人公補正を入れる場合は全体を 0.5倍程度に下げる。

主人公補正について: 純粋に現実の率を当てると、主人公の3割前後が5歳までに死ぬ。それ自体が「ランダム異世界」のおもしろさにもなるが、遊びとして続けたいなら、転生者には乳幼児期の死亡率を 0.2〜0.3倍にする「女神の加護」を入れ、その分家族や村の子どもには現実の率を当てる、という分け方がよい。

2段目の死因抽選: 第3節の頻度を重みにし、第4節の身分・職業倍率と世界補正を掛ける。年齢による制限をつける。

- infant: 0〜4歳のみ
- childbirth: 15〜45歳の女性で、その年に出産イベントがあったときのみ(出産1回ごとに 1〜1.7% の独立判定にしてもよい)
- old_age: 60歳以上(長命種は種族の寿命の7割以降)
- war: 戦争中かつ兵士・騎士・徴兵対象のとき重みを上げる
- hero_slain: 魔族・魔王軍・闇落ちフラグ持ちのみ
- demonlord_slain: 勇者パーティ所属または魔王軍侵攻地域のみ
- execution: 断罪・異端・反逆のフラグがあるとき重みを大きく上げる
- magic_cost: 魔力暴走・禁術・寿命消費スキルを持つとき

### 6.3 イベント抽選

年ごとに 0〜3件のイベントを抽選する。

- 年齢帯で候補を絞る(第2節の区分)。
- 世界条件で絞る(学院がない世界では学院イベントを除く、SFならSFの候補を混ぜる)。
- 前提フラグで絞る(婚約していなければ婚約破棄は起きない、冒険者登録していなければパーティ追放は起きない)。
- 重み: 「節目」イベント(洗礼・入学・登録・結婚・叙爵・引退)は該当年齢でほぼ確定、それ以外は common / normal / rare で抽選。
- 連鎖: 一部のイベントは後続を予約する。追放 → 覚醒(1〜3年以内に 40%)→ 元パーティの没落(20%)。婚約破棄 → 断罪(30%)→ 冤罪を晴らす(30%)または追放先での新生活。勇者選定 → 旅立ち → 四天王撃破 → 魔王戦(勝てば英雄、負ければ demonlord_slain)。

### 6.4 一生の「型」の分布の目安

ランダムに回したとき、だいたい次のような結果の分布になると、現実味と物語性の両方が出る。

| 一生の結末 | 目安の割合(転生主人公、女神の加護あり) |
|---|---|
| 子ども時代に死ぬ | 5〜10% |
| 青年期に冒険・戦争・事故で死ぬ | 20〜30% |
| 壮年・中年に病や事件で死ぬ | 25〜30% |
| 老年まで生きて老衰・持病で死ぬ | 25〜35% |
| 伝説的な死(魔王と相打ち、自己犠牲、竜との戦い) | 2〜5% |
| 消息不明・帰還・次の転生へ | 1〜3% |

加護なしの非転生者(家族・NPCの一生)では、子ども時代に死ぬ割合を 30〜40% にし、老年まで生きる割合を 20% 前後にすると、前近代の人口構造に近くなる。

### 6.5 死の文章化

死因カテゴリごとに、誰に看取られたかを付けると一生の締めくくりが印象に残る。06 の人間関係から生存している人物を1人選び、「〜に看取られて」「〜を守って」「〜の手で」と結びつける。長命種の伴侶や従魔が生き残っている場合は、主人公の死後の短い後日談(墓を守る、名を語り継ぐ)を付ける。
