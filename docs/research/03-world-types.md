# 03 世界観の型と、その世界での死に方

異世界に生まれ直した一生をランダムに転がすには、まず「どんな世界に落ちたか」を決める必要がある。この文書は、異世界ものでよく見る世界観を一般的な型として16種に分け、それぞれを数値のつまみで表せるようにするための下調べである。特定の作品の設定や固有名は使っていない。どの型も、多くの作品に共通する「よくある形」を抜き出したものだ。

後半では、実在の歴史人口学の数字を参照点として並べ、それを各世界の年齢別死亡率に写す方法を提案する。ファンタジーの死亡率に正解はないが、現実の数字を物差しにしておくと「この世界は中世より少し安全」「産業革命期の都市くらい不衛生」といった言い方ができ、世界ごとの差に筋が通る。

構成は次の通り。

1. 型を読むための共通の軸
2. 世界観の型 16種
3. 実在の歴史統計(参照点)
4. 歴史統計から読み取れる、ゲームに効く法則
5. パラメータ表の提案
6. 死亡率の作り方(式と実測値)
7. 補正の重ね方(戦争・疫病・飢饉・魔物・出産・身分・魔法医療)
8. 出典一覧

---

## 1. 型を読むための共通の軸

各型は同じ項目で書く。ゲーム側のパラメータと一対一で対応させるためである。

- 技術水準: 石器、青銅、鉄器、中世、近世、産業革命、現代、近未来、星間、の順。後の表では 0〜10 の数に直す。
- 魔法: 有無と強さ。誰が使えるか(生まれつき・血統・学習・契約)も書く。
- 異能: 魔法とは別系統の個人の特殊能力。スキル、加護、超能力、気、血統能力など。
- 種族構成: 人間だけか、エルフ・ドワーフ・獣人・魔族などが混ざるか。
- 魔物の密度: 町の外に出ると何が起きるか。
- 戦争の頻度: 国家間戦争、内乱、魔族との戦争。
- 医療水準: 治癒魔法やポーションを含めた、実際に手に入る医療。誰の手に届くかが肝心。
- 治安: 盗賊、殺人、決闘、私刑の多さ。
- 平均寿命の目安: 出生時平均余命(e0)と、成人まで生き延びた人の平均享年を分けて書く。この二つは大きく違う(3節参照)。
- 身分制度、典型的な職業、典型的な死因。
- ピクセルアートの手がかり: 色調、建物、小物。

## 2. 世界観の型 16種

### 2-1. 剣と魔法の中世欧州風(標準型)

異世界ものの基本形。石造りの城と城下町、麦畑の広がる農村、町の外の森と街道に魔物が出る。冒険者ギルドが職業として成立していて、魔物討伐や護衛が仕事になる。

- 技術水準: 中世後期から近世初頭。鉄器、水車、帆船、活版印刷が出始める程度。火薬はないか、あっても珍しい。
- 魔法: あり、普通。人口の一部(1割前後から数%)が使え、貴族に多い設定が定番。属性魔法(火・水・風・土)と治癒魔法。
- 異能: あってもスキル程度。転生者だけが特別な力を持つ構図が多い。
- 種族: 人間が多数派。エルフ・ドワーフ・獣人が少数派として町に混ざる。魔族は敵対勢力として国境の向こうにいる。
- 魔物の密度: 中。街道沿いはおおむね安全、森や山や遺跡は危ない。
- 戦争: 中。国境紛争が数十年に一度、魔王軍との戦争が物語の山場になりやすい。
- 医療: 中世相当に治癒魔法が足される。治癒魔法は教会か高額な治療院の独占で、農民の手には届きにくい。外傷は魔法で治るが、感染症や出産は魔法でも難しい扱いが多い。
- 治安: 町の中は衛兵がいて中程度、街道は盗賊が出る。
- 平均寿命の目安: e0 は30歳前後、20歳まで生きれば50代半ばまで。治癒魔法が普及した設定なら e0 は40近くまで上がる。
- 身分: 王族、貴族(公爵から男爵、騎士)、聖職者、平民(商人・職人・農民)、奴隷または農奴。冒険者は身分の外にいる流動層。
- 職業: 農民、職人(鍛冶・大工・織物)、商人、兵士、騎士、冒険者、聖職者、魔法使い、薬師、宿屋、吟遊詩人。
- 典型的な死因: 乳幼児期の感染症、出産、冒険者や兵士の戦闘死、魔物の襲撃、疫病、飢饉、事故(落馬・溺死・火事)。
- ピクセルアート: 緑と茶を土台に、空の青、屋根の赤茶。木組みの漆喰壁の家、石の城壁と塔、教会の尖塔、風車。小物は剣と盾、樽、麦袋、ギルドの掲示板、ランタン、木の看板。

### 2-2. ダークファンタジー

標準型から希望を削った世界。魔物が多く、領主は残酷で、疫病がしばしば村を消す。人は簡単に死に、英雄も報われない。

- 技術水準: 中世。標準型より一段低く描かれることが多い。
- 魔法: あり、強いが代償が重い。血・寿命・正気を払う。禁術や呪いが多い。
- 異能: 呪われた力、異形化。持つ者は迫害される。
- 種族: 人間中心。人外は怪物として扱われ、共存は少ない。
- 魔物の密度: 高。夜は町の外に出ない。辺境の村は定期的に滅びる。
- 戦争: 高。終わらない戦争、傭兵団、略奪。
- 医療: 低。治癒魔法はほぼ無いか、払える者だけのもの。瀉血や祈りが主流。
- 治安: 低。魔女狩り、私刑、異端審問。
- 平均寿命の目安: e0 は20歳台前半。20歳まで生き延びても40代半ばで死ぬことが多い。黒死病の時代の欧州が近い。
- 身分: 標準型と同じ構造だが、身分間の格差と暴力がより露骨。
- 職業: 農民、傭兵、墓掘り、処刑人、魔物狩り、異端審問官、修道士、行商、娼婦、盗賊。
- 典型的な死因: 魔物、戦争と略奪、疫病、飢え、処刑、呪い。
- ピクセルアート: 彩度を落とした灰と黒、血の赤と松明の橙だけが目立つ。崩れた城壁、焼けた村、枯れ木、絞首台、墓地、霧。小物は大剣、鎖、髑髏、蝋燭、ペスト医師風の仮面。

### 2-3. ゲーム的世界(ステータス・レベルが見える)

見た目は標準型に近いが、世界そのものにゲームの仕組みが組み込まれている。ステータス画面、レベル、スキル、職業(ジョブ)の神託。経験値を積めば人は強くなるので、強者と弱者の差が数値で開く。

- 技術水準: 中世から近世。ただしダンジョン産の魔道具が技術の穴を埋める。
- 魔法: あり、普通から強。スキルとして体系化されていて、習得手順がはっきりしている。
- 異能: 強。固有スキル、ユニークジョブ、加護。生まれたときや成人の儀で判明する。
- 種族: 人間、エルフ、ドワーフ、獣人、魔族。種族ごとにステータスの傾向がある。
- 魔物の密度: 中から高。ただし魔物は経験値と素材の源で、経済の一部になっている。ダンジョンが資源地帯。
- 戦争: 中。
- 医療: 中から高。ポーションが流通し、外傷は回復する。HPの考え方があるので「傷が治る」世界になりやすい。病気は別扱いのことが多い。
- 治安: 中。高レベルの犯罪者は止めにくい。
- 平均寿命の目安: e0 は35〜45歳。子供の死亡は中世並みだが、成人の外傷死がポーションで減る。高レベル者は老化が遅い設定もある。
- 身分: 貴族制に加えて、ジョブやレベルによる序列。冒険者ランク(SからFなど)が実質的な身分として働く。
- 職業: 冒険者(戦士・魔法使い・僧侶・盗賊・弓使い)、鍛冶師、錬金術師、テイマー、商人、ギルド職員、農民(戦闘ジョブを持たない人)。
- 典型的な死因: ダンジョンや魔物討伐での戦闘死(若い冒険者に集中)、外れジョブによる貧困、乳幼児期の病気。病死は少なめ。
- ピクセルアート: 明るい原色、くっきりした輪郭。ギルドの建物、ダンジョンの入口、市場。小物はステータスウィンドウの枠、宝箱、ポーション瓶(赤・青)、スライム、魔石、レベルアップの光。

### 2-4. 悪役令嬢もの・貴族社会/学園

舞台の中心が王都の貴族社会と、貴族の子女が通う学園になる型。婚約、社交界、派閥争い、断罪。命のやり取りより名誉と立場のやり取りが主になる。魔法学園の形をとることも多い。

- 技術水準: 近世から19世紀前半風。ドレスや舞踏会は18〜19世紀の欧州の雰囲気。紙、郵便、馬車が日常にある。
- 魔法: あり、普通。貴族の血統に宿る設定が多く、魔力の強さが家格と結びつく。
- 異能: 弱から普通。聖女の力、特殊な加護。
- 種族: ほぼ人間。精霊や妖精が添えられる程度。
- 魔物の密度: 低。王都は安全で、魔物は辺境の話。
- 戦争: 低から中。隣国との緊張はあるが、日常は平和。
- 医療: 貴族は高、平民は中。治癒魔法と宮廷医。
- 治安: 王都は高、ただし毒殺・暗殺・陰謀がある。
- 平均寿命の目安: 貴族なら e0 は40台、成人した貴族は60代まで生きる。近世欧州の上流層と同程度。平民はもっと短い。
- 身分: 王族、公爵・侯爵・伯爵・子爵・男爵、騎士爵、平民。特待生として平民が学園に入る構図が多い。家督・婚姻・持参金が人生を決める。
- 職業: 貴族の当主・夫人、侍女、執事、近衛騎士、宮廷魔術師、文官、商会主、学園の教師、聖職者、仕立屋。
- 典型的な死因: 出産(貴族女性でも高い)、毒殺・暗殺、断罪による処刑や追放後の困窮、決闘、乳幼児の病気。
- ピクセルアート: 白・金・パステル(薄桃、水色、ラベンダー)。宮殿、噴水のある庭園、学園の時計塔、舞踏会の広間、温室。小物は扇、ティーセット、手紙と封蝋、宝石、薔薇、婚約指輪。

### 2-5. 東洋風・和風

日本の戦国から江戸を下敷きにした型。妖怪や神が実在し、陰陽師や巫女や侍がいる。

- 技術水準: 中世から近世(戦国〜江戸相当)。鉄砲が入っている設定もある。
- 魔法: あり、普通。陰陽術、呪符、祝詞、式神。
- 異能: 普通。妖怪の血、神の加護、霊視。
- 種族: 人間に加えて妖怪・鬼・天狗・狐など。人に化けて暮らす妖も多い。
- 魔物の密度: 中。妖怪は夜と山に多い。
- 戦争: 戦国型なら高、太平の世型なら低。
- 医療: 中。漢方と鍼灸に加持祈祷。江戸時代の日本は都市の上下水が整っていて、同時代の欧州都市より衛生は良かったとされる。
- 治安: 太平の世なら高め(江戸期の日本は暴力死が少なかったと考えられている)、戦国なら低い。
- 平均寿命の目安: e0 は30〜40歳。乳児死亡が多く、成人すれば50〜60代まで。江戸期の農村の数字が参照点(3節)。
- 身分: 公家、武士(大名・旗本・足軽)、百姓、町人(職人・商人)、僧侶・神職、被差別の身分。家制度と長子相続。
- 職業: 百姓、侍、足軽、商人、職人(刀鍛冶・大工・染物)、陰陽師、巫女、僧、忍び、医者、遊女、飛脚、旅芸人。
- 典型的な死因: 乳幼児の病気(天然痘・麻疹)、飢饉、出産、戦(戦国型)、妖怪、火事、切腹や処刑。
- ピクセルアート: 墨色、朱、藍、若草、桜の薄紅。瓦屋根と木造の町家、鳥居と神社、天守、田んぼ、竹林、宿場町。小物は提灯、刀、お札、狐面、鈴、湯呑、草鞋。

### 2-6. 東洋風・中華風/仙侠・武侠

古代から中世の中国を下敷きにした型。後宮もの(宮廷の権力闘争)と、修行で強くなる仙侠・武侠ものに分かれる。仙侠では修行を積むと寿命が延び、数百年生きる者もいる。

- 技術水準: 古代から中世(漢〜明相当)。
- 魔法: 仙侠なら強(仙術・丹薬・法宝)、後宮ものなら弱。
- 異能: 強。気・内功・霊根の資質。資質の有無が生まれで決まり、人生を大きく分ける。
- 種族: 人間に加えて妖・獣の精・仙人・魔。修行で人をやめていく者がいる。
- 魔物の密度: 中から高。妖獣が山野にいる。
- 戦争: 中。王朝交代期は高。門派同士の抗争。
- 医療: 中。漢方、鍼、丹薬。仙侠では丹薬が劇的に効く。
- 治安: 中から低。江湖の暴力、仇討ち。
- 平均寿命の目安: 凡人の e0 は25〜35歳、成人すれば50代。修行者は段階ごとに寿命の上限が上がり、100〜数百年。凡人と修行者で別の死亡率を持たせる必要がある。
- 身分: 皇帝、皇族、官僚(科挙)、士大夫、農民、商人、奴婢。後宮には妃嬪の位階、宦官。仙侠では門派内の序列(外門弟子・内門弟子・長老)。
- 職業: 農民、官吏、武人、宦官、宮女、商人、薬師、道士、門派の弟子、侠客、鏢局(護送業)。
- 典型的な死因: 凡人は病・飢饉・戦乱。修行者は修行の失敗(走火入魔)、門派抗争、秘境での事故、寿命の天井。後宮では毒と陰謀。
- ピクセルアート: 朱と金、翡翠の緑、墨。反り屋根の楼閣、城門、雲のかかった山の上の宗門、竹林、蓮池。小物は剣、扇、香炉、丹薬の瓢箪、巻物、霊石、玉の飾り。

### 2-7. スチームパンク/魔導産業革命

蒸気機関か魔導機関で産業革命が起きた世界。工場の煙突、飛行船、鉄道、労働者の町。魔法が技術に組み込まれて「魔導具」として量産される。

- 技術水準: 19世紀相当。蒸気機関、鉄道、電信、初期の銃器。
- 魔法: 弱から普通。個人の才能より、魔石を燃料にした機械として使われる。
- 異能: 弱。
- 種族: 人間中心。ドワーフや獣人が工場労働者として描かれることもある。
- 魔物の密度: 低から中。都市の外は開拓前線。
- 戦争: 中。列強の植民地戦争、大砲と銃。
- 医療: 中。外科は進むが、細菌の理解が追いついていない時期。都市は不衛生でコレラや結核が流行る。
- 治安: 中。都市の貧民街は危ない。
- 平均寿命の目安: 国全体の e0 は40歳前後だが、工業都市の労働者は25〜30歳まで落ちる。19世紀イギリスの数字がほぼそのまま使える(3節)。
- 身分: 法的な身分制は薄れ、階級(貴族・資本家・中産階級・労働者)が実質的な身分になる。
- 職業: 工場労働者、炭鉱夫、機関士、技師、発明家、記者、警官、商人、事務員、使用人、飛行船乗り、探偵。
- 典型的な死因: 感染症(結核・コレラ・チフス)、工場と炭鉱の事故、乳児死亡(都市で高い)、大気汚染、戦争。
- ピクセルアート: 真鍮、銅、煤けた茶と灰、ガス灯の黄色。レンガの工場、煙突、鉄骨の駅舎、飛行船、時計台、石畳。小物は歯車、懐中時計、ゴーグル、蒸気管、山高帽、新聞。

### 2-8. 近未来SF/サイバーパンク

高度に機械化された都市と、そこから落ちこぼれた人々の世界。企業が国家より強く、体を機械に置き換えられる。異世界ものでは「魔法の代わりに技術がある世界」に転生する形で使われる。

- 技術水準: 近未来。義体、AI、ネットへの神経接続。
- 魔法: なし、または電脳魔術のように技術と混ざったもの。
- 異能: 普通。義体やインプラントによる後付けの能力、超能力者。
- 種族: 人間、改造人間、AI、クローン、アンドロイド。
- 魔物の密度: 低。代わりにギャングと企業の私兵がいる。
- 戦争: 中。企業間の抗争、代理戦争。
- 医療: 高だが金次第。富裕層は臓器交換で長生きし、貧困層は治療を受けられない。
- 治安: 低から中。地区による差が極端。
- 平均寿命の目安: 全体の e0 は70前後、富裕層は90超、下層は50〜60台。現代の格差を拡大した形。
- 身分: 法的な身分はなく、企業の社員ランクと市民権の有無と所得で分かれる。
- 職業: 企業の社員、技術者、ハッカー、傭兵、闇医者、配達人、警官、ストリートの商人、娯楽業。
- 典型的な死因: 暴力(銃撃・抗争)、薬物、義体の拒絶反応、労働災害、生活習慣病、治療を受けられない病気。
- ピクセルアート: 黒と紫を背景にネオンの桃・青緑。高層ビル、雨の路地、看板の漢字やカナ、屋台、高架。小物はモニター、ケーブル、義手、ドローン、自販機、ホログラム。

### 2-9. 宇宙/スペースオペラ

星間国家と宇宙艦隊の世界。惑星ごとに文明の段階が違い、辺境は開拓時代そのもの、中心は超先進文明という差を作れる。

- 技術水準: 星間。超光速航行、人工重力、高度な医療。
- 魔法: なしが多い。超能力が魔法の位置にある。
- 異能: 普通から強。超能力者は希少で、軍や宗教団体に組み込まれる。
- 種族: 人類と複数の異星種族。
- 魔物の密度: 低から中。未開惑星の原生生物、宇宙怪獣。
- 戦争: 高。星間戦争で艦隊ごと消える。
- 医療: 高。再生医療、延命処置。辺境惑星では低い。
- 治安: 中心惑星は高、辺境は低(海賊)。
- 平均寿命の目安: 中心惑星の市民なら e0 は85以上、延命処置で100超。軍人や辺境民は大きく下がる。
- 身分: 帝国型なら貴族制が復活していることが多い。共和国型なら市民と非市民。
- 職業: 艦隊軍人、パイロット、技術者、商人、密輸業者、外交官、科学者、農業惑星の農民、鉱山労働者、傭兵。
- 典型的な死因: 戦闘(艦の撃沈)、事故(真空・放射線)、未知の病原体、海賊、高齢。
- ピクセルアート: 濃紺と黒の宇宙、白い船体、青やオレンジの推進光。宇宙ステーション、艦橋、ドーム都市、異星の荒野。小物は光線銃、宇宙服、端末、星図、カプセル。

### 2-10. 現代世界(ダンジョンが出現した現代・現代異能)

異世界に行くのではなく、現代社会に異世界の要素が入り込む型。ある日ダンジョンが出現した現代日本、あるいは異能者が生まれる現代。役所や企業が探索者を管理し、配信やランキングが絡む。

- 技術水準: 現代。
- 魔法: 弱から普通。ダンジョン内やダンジョン由来の力として。
- 異能: 普通から強。覚醒者・探索者だけが持つ。人口の数%以下。
- 種族: 人間。ダンジョンから出てくるモンスター。
- 魔物の密度: ダンジョン内は高、外は低。ただしダンジョンからの溢れ出しが災害になる。
- 戦争: 低(先進国の場合)。
- 医療: 高。現代医療にポーションが加わる。
- 治安: 高。ただし異能者の犯罪は大事件になる。
- 平均寿命の目安: 一般人は現代日本並み(e0 は84前後)。探索者は若年期の死亡が上乗せされ、職業として危険な部類になる。
- 身分: 現代の社会階層に、探索者ランクや覚醒の有無が重なる。
- 職業: 会社員、学生、公務員、探索者、ギルドや協会の職員、配信者、鑑定士、素材加工業、自衛隊・警察の対策部隊。
- 典型的な死因: 一般人は高齢の病気(がん・心疾患・脳血管疾患)。探索者はダンジョン内の戦闘死。溢れ出し災害での巻き込まれ。
- ピクセルアート: 現代の灰色の都市、コンビニの白、信号、夕焼けの橙。ビル、駅前、学校、住宅街、その中に開いた異質なダンジョンの門(紫や黒)。小物はスマホ、自販機、制服、ヘルメット、配信のコメント欄。

### 2-11. ポストアポカリプス

文明が崩れた後の世界。核戦争、疫病、魔物の大発生、魔法災害など原因はさまざま。廃墟から昔の技術を掘り出して使う。

- 技術水準: 現代の遺物と、鉄器から近世の手作業が混ざる。作れないが使えるものがある。
- 魔法: なし、または災害後に目覚めた弱い魔法。
- 異能: 普通。突然変異、放射線や魔素による変異。
- 種族: 人間、変異人類、変異生物。
- 魔物の密度: 高。
- 戦争: 高。集落間の略奪、物資の奪い合い。
- 医療: 低。昔の薬の残りを奪い合う。
- 治安: 低。集落の内側だけに秩序がある。
- 平均寿命の目安: e0 は25歳前後。成人しても40代半ばで死ぬことが多い。崩壊直後は特に悪い。
- 身分: 集落の長、戦士、技術者(機械を直せる者は重宝される)、労働者、奴隷。
- 職業: 漁り屋(廃墟あさり)、護衛、農夫、修理工、商隊、医者もどき、略奪者、伝令。
- 典型的な死因: 暴力、変異生物、感染症、汚染、飢え、渇き。
- ピクセルアート: 砂色、錆の赤茶、くすんだ緑。崩れたビル、錆びた車、バラックの集落、給水塔、焚き火。小物はガスマスク、缶詰、ジェリカン、スクラップの武器、ラジオ。

### 2-12. 海洋/群島

島々と海が世界の大部分を占める型。航海と交易と海賊。島ごとに文化が違う。

- 技術水準: 中世から近世(帆船の時代)。
- 魔法: 普通。風や水を操る魔法が航海の技術として重宝される。
- 異能: 弱から普通。海の加護、人魚の血。
- 種族: 人間、人魚・魚人、海の獣人。
- 魔物の密度: 中。海の魔物(大海蛇、大蛸)と嵐。
- 戦争: 中。海軍と海賊、島同士の争い。
- 医療: 中から低。長い航海では壊血病。
- 治安: 港は中、海上は低。
- 平均寿命の目安: 島で暮らす人は e0 30前後、船乗りの男性は成人後の死亡が高い。
- 身分: 島の王や首長、商人組合、船長、水夫、奴隷。
- 職業: 漁師、船乗り、船大工、交易商人、海賊、海軍士官、真珠採り、灯台守、潜り手、航海士。
- 典型的な死因: 海難(嵐・座礁・溺死)、海の魔物、壊血病などの船上の病、海賊との戦闘、熱帯の感染症。
- ピクセルアート: 碧い海、白い砂、椰子の緑、夕日の橙。高床の家、港の桟橋、灯台、帆船、岩礁。小物は錨、ロープ、羅針盤、宝の地図、魚、貝殻、樽。

### 2-13. 砂漠/遊牧

砂漠と草原と、点在するオアシス都市の型。隊商交易、遊牧民の部族、古代遺跡。

- 技術水準: 古代から中世。
- 魔法: 普通。精霊(ジン的なもの)との契約、水を呼ぶ魔法。
- 異能: 弱から普通。
- 種族: 人間、砂漠の獣人、精霊。
- 魔物の密度: 中。砂の魔物、毒虫。
- 戦争: 中から高。部族間の抗争、騎馬の襲撃。
- 医療: 中から低。オアシス都市には医学の伝統がある設定もある。
- 治安: 都市の中は中、砂漠は低。
- 平均寿命の目安: e0 は30前後。渇きと暑さで子供が死にやすい。
- 身分: 王やスルタン的な支配者、部族長、商人、遊牧民、奴隷。部族の血縁が身分の基本。
- 職業: 遊牧民、隊商の商人、駱駝引き、護衛、水売り、絨毯織り、占い師、遺跡掘り、騎馬戦士。
- 典型的な死因: 渇き、熱、砂嵐、部族間の襲撃、毒虫、乳幼児の下痢症。
- ピクセルアート: 砂の黄土、空の濃い青、日干し煉瓦の淡い橙、布の赤や藍。丸屋根の家、オアシスの椰子、市場の天幕、遊牧の天幕、遺跡の柱。小物は壺、水袋、絨毯、ランプ、曲刀、駱駝。

### 2-14. 獣人が主の世界

人間が少数派か、いない世界。狼・猫・兎・熊などの獣人が種族ごとに社会を作る。種族ごとの身体能力と寿命の差、捕食と被食の関係が社会の緊張になる。

- 技術水準: 中世が多い。
- 魔法: 弱から普通。種族ごとの得意不得意。
- 異能: 普通。獣化、鋭い感覚。
- 種族: 獣人の各種族。肉食系と草食系、大型と小型。
- 魔物の密度: 中。
- 戦争: 中。種族間の対立。
- 医療: 中から低。
- 治安: 中。
- 平均寿命の目安: 種族ごとに変える。小型・草食系は成長が早く寿命が短い(e0 25前後、上限60前後)、大型系は成長が遅く長寿(上限90前後)。これは現実の動物の体の大きさと寿命の関係を借りた設定。
- 身分: 種族の序列が身分になりやすい。群れの長、氏族。
- 職業: 狩人、牧人、戦士、職人、商人、斥候、運び屋。種族の能力に合った仕事に偏る。
- 典型的な死因: 種族間の暴力、狩りの事故、魔物、多産種族では出産。
- ピクセルアート: 森の緑と木の茶。木の上の家、巣穴のような住居、集会場の大樹。小物は弓、毛皮、骨の飾り、木の実、種族ごとの耳と尻尾の描き分け。

### 2-15. 神話時代

神々がまだ地上にいる古い時代の型。英雄が神の血を引き、怪物が実際に暴れる。ギリシャ神話や北欧神話のような雰囲気。

- 技術水準: 青銅器から初期鉄器。
- 魔法: 強。ただし人が使うのではなく、神と精霊の力。
- 異能: 強。神の子、半神、加護。
- 種族: 人間、神、巨人、精霊、怪物。
- 魔物の密度: 高。
- 戦争: 高。都市国家の戦争、神々の争いに巻き込まれる。
- 医療: 低。神殿での祈り。
- 治安: 低。
- 平均寿命の目安: 凡人の e0 は20歳台前半から半ば。古代ローマの推計が参照点(3節)。半神は別の時間軸。
- 身分: 王、神官、戦士貴族、自由民、奴隷。
- 職業: 羊飼い、農民、戦士、神官、巫女、鍛冶、船乗り、詩人、奴隷。
- 典型的な死因: 戦争、怪物、神の怒り(天災)、疫病、乳幼児の病気、出産。
- ピクセルアート: 大理石の白、空の青、オリーブの緑、金。神殿の列柱、円形劇場、石の城壁、葡萄畑、海と岬。小物は青銅の兜と円盾、竪琴、壺、月桂冠、雷。

### 2-16. 辺境開拓/スローライフの村

戦いより暮らしが主の型。追放されたり転生したりした主人公が辺境の村や森で畑を耕し、住人を増やしていく。世界観としては標準型の辺境部分を切り出したもの。

- 技術水準: 中世。主人公が知識で底上げする余地が大きい。
- 魔法: 普通。生活魔法(火起こし・水出し・浄化)が普及しているとして描かれる。
- 異能: 普通(主人公に偏る)。
- 種族: 人間に加え、エルフ・ドワーフ・獣人などが移住者として集まる。
- 魔物の密度: 中。村の外の森。
- 戦争: 低。
- 医療: 中から低。辺境なので医者がいない。
- 治安: 中。村の中は安全。
- 平均寿命の目安: e0 は35前後。浄化魔法が水を清潔にする設定なら、乳幼児の下痢症が減って e0 は40台まで上がり得る。
- 身分: 辺境では身分がゆるむ。村長、開拓民、移住者。
- 職業: 農民、狩人、木こり、薬草採り、鍛冶、大工、行商、村の医者。
- 典型的な死因: 乳幼児の病気、魔物、冬の寒さと食糧不足、事故、出産。
- ピクセルアート: 柔らかい緑と黄、木の茶。丸太小屋、畑、柵、井戸、小川、森の縁。小物は鍬、籠、野菜、鶏、薪、薬草。

## 3. 実在の歴史統計(参照点)

ここからは現実の数字。どれも推計で、研究者によって幅がある。数字そのものより「どの程度の桁か」と「指標どうしの関係」を掴むために並べる。

### 3-1. 指標の読み方

- 出生時平均余命(e0): 生まれた子が平均何年生きるか。乳幼児の死亡に強く引っぱられる。
- 乳児死亡率(q0, 1q0): 生まれた子が1歳までに死ぬ割合。出生1000あたりで書かれることが多い。
- 5歳未満死亡率(5q0): 5歳までに死ぬ割合。
- 20歳時平均余命(e20): 20歳まで生きた人があと何年生きるか。20+e20 が「成人した人の平均享年」になる。
- 妊産婦死亡: 出産1件あたりの母親の死亡。歴史研究では出生1000あたり、現代統計では出生10万あたりで書かれる。生涯で何度も産むので、女性一人の生涯リスクは1件あたりの率の数倍になる。

e0 が30歳と聞くと「30歳で死ぬ世界」と思いがちだが、実際は乳幼児の大量死が平均を下げている。前近代でも、大人になった人の多くは50〜60代まで生きた。このずれをゲームに正しく入れることが、この文書でいちばん大事な点である。

### 3-2. 前近代全般(狩猟採集民・前近代の子供)

- Volk & Atkinson (2013) は、狩猟採集民20集団と歴史上の43集団の死亡データを集め、乳児死亡率を約27%、思春期までの死亡率を約47.5%と推計した。前近代では生まれた子のおよそ半分が大人になれなかった、という目安になる。集計の要約版では平均乳児死亡率26.8%、子供期の死亡率48.8%とされている。
- Gurven & Kaplan (2007) は現存する狩猟採集民・園耕民の生命表を比べ、e0 は低いが、15歳まで生き延びた人は60代から70代まで生きることが多く、成人の死亡の最頻年齢は70歳前後(68〜78)だったと報告した。出生者のおよそ6割が15歳に、4割が45歳に到達する。人間の体はもともと70年前後生きるようにできていて、前近代の短命は主に子供期と事故・暴力・感染症による、という見方の根拠になっている。
- 戦争による死: Keeley (1996) は国家以前の社会で戦争が死因に占める割合が高かったことを示し、Bowles (2009) は考古学と民族誌の資料から、先史・狩猟採集社会の死亡のおよそ14%が集団間の暴力によると推計した。

### 3-3. 古代ローマ

- Frier (1982) はローマの法学者ウルピアヌスの年金計算表を手がかりに、ローマ帝国の e0 を20〜30歳と推計した。Scheidel らもおおむね20代半ばの e0 を想定している。人口学者の標準生命表(Coale-Demeny の Model West)の低い水準(e0 が25前後の水準 3)が当てはめられることが多い。
- この水準では乳児の3割近くが1歳までに死に、5歳までに4割以上が死ぬ。神話時代やダークファンタジーの参照点に使える。

### 3-4. 中世ヨーロッパ

- 平均寿命: 中世イングランドの e0 は30歳前後とされることが多い。Russell (1948) はイングランドの土地保有者の記録から、21歳に達した男性が黒死病以前は60代前半まで生きたと推計した。ただし土地保有者は上流寄りの集団である。
- 成人後の余命: Harvey (1993) はウェストミンスター修道院の修道士の死亡記録を分析した。修道士は食事も住居も恵まれていたにもかかわらず、15世紀のあいだに20歳時の平均余命が8年ほど縮んだという。修道院という閉じた集団に疫病が繰り返し入り込んだためと考えられている。恵まれた成人でも20歳時の余命が20〜30年台に落ちることがあった、という目安になる。
- 貴族の戦死: Cummins (2017) は西暦800〜1800年の欧州貴族約12万人の生没年を集め、1550年以前には貴族男性のおよそ3割が戦死していたが、1550年以降は5%未満に下がったと報告した。また Eisner (2011) は600〜1800年の欧州君主の死因を調べ、暗殺や戦死などの暴力死が全体の約22%を占めたとした。剣と魔法の世界で騎士や貴族の男子が戦死する確率は、このくらいの桁で考えると現実味がある。
- 殺人: Eisner (2003) の長期の犯罪史研究では、中世後期の欧州の殺人率は人口10万あたり年20〜50件ほどで、現代西欧(1件前後)の数十倍だった。これは治安パラメータの物差しになる。
- 黒死病: 1347〜1351年の流行で欧州人口の3〜5割が死んだとするのが一般的な見方で、Benedictow (2004) は約6割と高めに推計している。その後も十数年おきに再流行し、1361年の流行は子供の死亡が多かったことで知られる。
- 飢饉: 1315〜1317年の大飢饉では、北欧州の人口の5〜10%ほどが死んだと推計されている(Jordan 1996)。
- 三十年戦争(1618〜1648): ドイツ地域の人口は戦争と疫病と飢饉で2〜3割減ったとされ、地域によっては半減した。戦争の害の大半は戦闘ではなく、軍隊が運ぶ疫病と略奪による飢えだった。

### 3-5. 近世ヨーロッパ(イングランドの家族復元研究)

- Wrigley & Schofield (1981) は教区簿冊からイングランドの人口史を復元し、1541〜1871年の e0 が30代前半から40歳前後のあいだで上下していたことを示した。17世紀後半が低く、18世紀後半から上がる。
- 乳児死亡率は16〜18世紀のイングランドで出生1000あたり150〜200ほど(Wrigley ほか 1997)。イングランドは当時の欧州の中では低い方で、フランスや南ドイツの一部では250〜300を超える地域もあった。
- 妊産婦死亡: Schofield (1986) の研究と、その後のケンブリッジ人口史グループの整理では、前工業期イングランドの妊産婦死亡は出産1000件あたり平均12件前後、17世紀半ばの最悪期で17件ほど、19世紀初めにかけて下がった。Alter らの研究では1650〜1800年の平均を1000件あたり10件としている。女性が生涯に5〜6回出産すれば、生涯のうちに出産で死ぬ確率は5〜7%ほどになる。

### 3-6. 江戸時代の日本

- 史料: 江戸時代の村には毎年の宗門改帳(宗門人別改帳)があり、1671年以降ほぼ全国で作成された。速水融はこれを使って日本の歴史人口学を切り開いた。
- 乳児死亡率: 鬼頭宏は宗門改帳と懐妊書上帳を突き合わせ、近世後期の農村の乳児死亡率を出生1000あたり188と推計した(速水編『近代移行期の人口と歴史』2002 所収)。別の史料では182という値もある。宗門改帳は生まれてすぐ死んだ子を載せないことがあるので、それを補正した値である。
- 平均寿命: 江戸時代の農村の e0 は30代から40歳前後とされることが多い。地域と時期の差が大きく、ここでは幅として扱う。間引き(嬰児殺し)の存在が乳児死亡の数字を読みにくくしている。
- 飢饉: 享保(1732)、天明(1782〜1787)、天保(1833〜1837)の三大飢饉。天明の飢饉では、幕府の人口調査で1780年から1786年のあいだに全国人口が90万人以上減っており、東北の諸藩では人口の1〜2割を失ったところもある。
- 治安と衛生: 江戸期の日本は同時代の欧州と比べて戦争がほとんどなく、都市の上水と屎尿の農村還流によって都市衛生も比較的良かったとされる。和風・太平型の世界で暴力死を低く、感染症を中程度に置く根拠になる。

### 3-7. 古代〜近世の中国

- 中国の歴史人口は史料の性質から幅が大きい。清代については Lee & Campbell (1997) が遼寧の戸籍を、Lee & Wang (1999) が皇族の系譜などを使って分析しており、清代の e0 は男女とも30歳前後、女児の間引きによって女性の乳幼児死亡が高かったことが示されている。
- 王朝交代期の戦乱と飢饉では、登録人口が数十年で大きく落ち込むことが繰り返し記録されている(ただし登録人口の減少には戸籍の崩壊も含まれる)。中華風世界で「王朝末期」を選んだ場合に戦争と飢饉の確率を大きく上げる根拠として使える。
- 確かな数字が少ないので、中華風世界の基準は近世欧州と江戸日本の中間に置くのが無難である。

### 3-8. 19世紀の産業革命期

- イングランド・ウェールズ全体の e0 は1840〜1870年代にかけて40〜41歳前後で、ほぼ横ばいだった。乳児死亡率は19世紀を通じて出生1000あたり150前後から下がらず、本格的に下がるのは1900年以降である。
- 都市と農村の差: Chadwick の1842年の衛生報告は、職業と地域別の平均死亡年齢を示した。マンチェスターの労働者は17歳(表によっては15歳)、農村のラトランドの専門職・上流は52歳だった。この平均死亡年齢は乳幼児の死亡を含むので e0 に近い意味の数字である。Szreter & Mooney (1998) は、1830〜1850年代のマンチェスターやリヴァプールのような大工業都市で e0 が30歳を切るほど落ち込んだと推計している。
- スチームパンク世界では「国の平均」と「工場都市の下層」を分けて持つと、この時代らしさが出る。

### 3-9. 現代の先進国

- 日本: e0 は男性81歳前後、女性87歳前後(厚生労働省の簡易生命表、2020年代)。5歳未満死亡率は出生1000あたり2.4(UNICEF、2024年)、乳児死亡率は2を切る。妊産婦死亡は出生10万あたり数件。殺人は人口10万あたり年0.2件ほど。
- 現代の死因は高齢期のがん・心疾患・脳血管疾患が中心で、若い人の死因は事故と自殺が上位になる。

### 3-10. 現代の紛争国・高死亡国

- 5歳未満死亡率(2024年): 世界平均は出生1000あたり37.4。ナイジェリア約116、ニジェール約111、ソマリア約101、チャド約97(UNICEF・UN IGME と、それを使った分析による。資料によって数値に幅がある)。最も高い国の子供は、最も低い国の子供よりおよそ57倍死にやすい。
- 妊産婦死亡: 世界平均で出生10万あたり220前後(WHO ほか、2020年推計)。南スーダンやナイジェリアでは1000を超える。日本の数百倍である。
- e0 は、これらの国で50代前半から60歳前後。前近代よりはずっと長いが、子供の死亡は近世欧州の3分の1から半分程度残っている。紛争国の数字は、近代医療の一部だけが届く世界(魔導産業期の辺境、宇宙の辺境惑星、崩壊から数十年たったポストアポカリプス)の参照点になる。

## 4. 歴史統計から読み取れる、ゲームに効く法則

1. 前近代の短命は子供期の死でほぼ説明がつく。大人の寿命の上限は昔からあまり変わっていない。だから「大人になれば普通に老いて死ぬ」部分と、「子供期にふるい落とされる」部分を別のつまみにする。
2. 医療の進歩はまず子供の死を減らす。治癒魔法やポーションが「誰に届くか」で効き方が変わる。外傷にしか効かない治癒魔法は、戦士の死を減らすが乳児死亡はほとんど減らさない。乳児の死因の大半は感染症と栄養不良だからである。浄化魔法(清潔な水)の方が乳児死亡にはよく効く。
3. 戦争の害は戦闘より疫病と飢えで出る。三十年戦争がその典型。戦争イベントは兵士の戦死だけでなく、同じ年の疫病と飢饉の確率を引き上げるようにすると現実に沿う。
4. 暴力死の多さは身分で偏る。中世では貴族男性の戦死率が平民より高かった(Cummins)。騎士や冒険者の家に生まれた男子は、上流で医療に恵まれる分と戦場に出る分が打ち消し合う。
5. 出産は女性の成人期の大きな死因だった。1回あたり1%前後、生涯で5%前後。治癒魔法がある世界でもここを0にすると前近代らしさが消えるので、魔法医療の補正は弱めにかける。
6. 都市は農村より死にやすかった(近代以前)。人が密集すると感染症が回る。19世紀の工業都市はその極端な形。現代になって逆転する。
7. 大きな疫病は「数十年に一度、人口の何割か」という形で来る。毎年の基底ハザードに混ぜるより、まれなイベントとして別に転がす方が、人生ごとの運の差が出てゲームとして面白い。

### 5-4. 値をどう対応させたか

- q0 と q5 は歴史の数字をほぼそのまま使った。中世欧州風の0.22は中世イングランドの0.20〜0.30の下寄り、和風の0.19は鬼頭宏の188に合わせた。ゲーム的世界と貴族社会は近世イングランドの上流層(0.15)、スチームパンクは19世紀イングランド全体の0.15とした。
- q5 と q0 の比は、Coale-Demeny の標準生命表で乳児死亡率が0.15〜0.30の水準のとき、5歳未満死亡率が乳児死亡率のおよそ1.6〜1.7倍になる関係に合わせた。現代では比が1.3前後に縮むので、現代系の行はそれに合わせた。
- c(成人の基底ハザード)は、感染症・事故・暴力をまとめた「年齢に関係ない死」で、前近代では年1%前後が目安になる。これを0.010にすると、20〜40歳の20年間でおよそ18%が死ぬ。ダークファンタジーとポストアポカリプスは魔物と暴力の分を足して2%台にした。
- b(ゴンペルツの傾き)は、現代の先進国で0.08〜0.10(死亡率が7〜9年で倍になる)、前近代では成人の死亡に占める外因の割合が大きく、見かけの傾きが0.06〜0.08に下がるとされる。前近代型は0.075、現代型は0.09〜0.10とした。仙侠の凡人は0.060にして、修行者を同じ式の延長で扱えるよう上限年齢を150にしてある(修行者は7-7節の補正で a30 をさらに下げる)。
- a30 は、前近代で 0.003〜0.0045、現代日本で 0.00025 とした。前近代の高い値は、栄養不良と慢性感染症で体が早く傷むことを表している。

## 6. 死亡率の作り方(式と実測値)

### 6-1. 年齢ごとの年死亡確率

1歳刻みで、その年に死ぬ確率 q(x) を次のように決める。

- 0歳: q(0) = q0
- 1〜4歳: q(x) = 1 − ((1 − q5) / (1 − q0)) の4乗根。これで 0〜4歳を通した死亡がちょうど q5 になる。
- 5〜14歳: q(x) = ch(一定)。前近代の子供期の死亡は5歳を過ぎると大きく下がり、10代前半が一生で最も死ににくい時期になる。
- 15歳以上: ハザード h(x) = c + a30 × exp(b × (x − 30))、q(x) = 1 − exp(−h(x))。ゴンペルツ=メイカム型と呼ばれる形で、c が年齢に関係ない死、後半が老化による死。
- max 歳で必ず死ぬ。

毎年 q(x) で死亡判定を転がせば、一生分の死亡年齢がこの生命表に沿って分布する。5-3節の e0 などはこの式を出生から max まで1歳刻みで回して実際に計算した値である(推測ではなく計算値)。

### 6-2. 世界型の値を動かしたときの効き方

- q0 と q5 を動かすと e0 は大きく動くが、成人の平均享年はほとんど動かない。ゲーム的世界(q0 0.15)と中世欧州風(q0 0.22)は e0 が7歳近く違うが、成人の享年は同じ55である。
- c を動かすと成人の享年が動く。0.010から0.022に上げると、成人の享年は9年ほど下がる(中世欧州風とダークファンタジーの差の大部分)。
- a30 と b は高齢期の形を決める。60歳到達率は a30 に敏感で、中世欧州風の24%に対して現代日本は94%。

### 6-3. 新しい世界型を作るとき

5-3節の表をそのまま使うのがいちばん簡単で、歴史との対応も保てる。表にない型を作る、あるいは二つの型を混ぜるときは、近い2行の値を線形に補間するのが無難である(例: 海洋と砂漠の中間なら各値の平均)。

つまみから q0 を直接導きたい場合の目安は次の式。

- q0 = 0.30 × (1 − medicine / 10)^2 + 0.002、tech が 5 以下ならさらに 0.05 を足す

表の16行で試すと、ずれは最大で ±0.06 ほど(和風・スチームパンクで低く、獣人・砂漠で高く出る)。目安としては使えるが、表に値がある型は表を優先する。c・a30・b については、つまみからの一次式を試したところ現代型で一桁ずれたので、式は提案しない。表の値か補間を使う。

戦争・疫病・飢饉は基底に混ぜず、7節のイベントとして別に転がす。

## 7. 補正の重ね方

基準の生命表は「その世界の平均的な平民」のものとして扱い、個人の属性とイベントで補正をかける。補正は掛け算か足し算で重ね、最後に q を 0〜1 に収める。

### 7-1. 戦争

- 年あたりの戦争発生確率 = war × 0.012(war 4 で約5%、つまり20年に一度ほど。war 8 で約10%)。
- 戦争の年に兵士・騎士・傭兵として従軍している者の死亡確率: 前近代で 1回の戦役あたり 5〜15%。Cummins の貴族男性の戦死約3割(生涯)は、成人の30年間に数回の戦役に出て1回あたり1割前後死ぬ、という形で再現できる。
- 戦争の年は、同じ年と翌年の疫病・飢饉の確率を 2倍にする(三十年戦争型の害)。民間人には c に 0.005〜0.02 を足す(略奪と行軍路)。

### 7-2. 疫病

- 大疫病: 年あたり 0.02〜0.03 の確率(30〜50年に一度)。起きた年はその地域の全員に 0.10〜0.40 の追加死亡確率。黒死病級は 0.3〜0.6 だが、一生に一度あるかないかにする。medicine と tech が高いほど発生確率と死亡率を下げ、tech 7 以上ではほぼ無効にする。
- 小流行(天然痘・麻疹・赤痢など): 年 0.10 の確率で、0〜9歳に 0.03〜0.08 を追加。これは基準の q0・q5 に既に含まれていると見なして、使うなら基準を少し下げる。二重に数えないよう注意。
- 都市補正: tech 6 以下で都市に住む者は c と ch を 1.3〜1.5倍。19世紀の工業都市下層は 2倍。

### 7-3. 飢饉

- 年あたり確率: tech 0〜5 で 0.03〜0.05(20〜30年に一度)、tech 6 で 0.01、tech 7 以上でほぼ 0。
- 起きた年の追加死亡: 0.03〜0.10(1315年の大飢饉が5〜10%)。子供と高齢者に 2倍、貴族には 0.3倍。天明の飢饉のように東北で人口の1〜2割を失った例もあるので、辺境・寒冷地は上限を 0.2 まで許す。

### 7-4. 魔物と職業

- danger は基準の c に既に入っているが、職業で倍率をかける。
  - 冒険者・魔物狩り・探索者: c を 3〜5倍、ただしランクやレベルが上がるほど倍率を下げる(若手が死に、生き残った者が強くなる形)。
  - 兵士・騎士: 平時は 1.5倍、戦時は 7-1節。
  - 農民・職人・商人: 1倍。行商・隊商は 1.5倍。
  - 船乗り・漁師(海洋型): 1.8倍。炭鉱夫・工場労働者(スチームパンク型): 1.5〜2倍。
  - 貴族の当主・文官・聖職者: 0.6〜0.8倍。
- 現代ダンジョン型の探索者は、一般人の生命表に年 0.01〜0.03 の職業死亡を足す。現代の危険職(漁業や林業)の死亡率は年 0.0001〜0.001 なので、それより一桁から二桁危ない職業として描くことになる。

### 7-5. 出産

- 出産1回ごとに母親の死亡判定をする。基準は 1回あたり 0.010〜0.015(前近代のイングランドの平均)。
- medicine による補正: medicine 0〜3 で 0.012〜0.017、4〜5 で 0.008〜0.010、6 で 0.005、7 で 0.0005〜0.001(紛争国並み)、9〜10 で 0.00003〜0.0001(現代日本並み)。
- 治癒魔法がある前近代世界でも、平民には 0.008 程度までしか下げない。出産を安全にするのは魔法の強さより、清潔さと難産への対処だったからである。貴族や聖女の加護を受けた者は 0.003 まで下げてよい。
- 子の数: 前近代の既婚女性で4〜7人。出産のたびに判定するので、多産の人生ほど母親の死が起こりやすくなる。

### 7-6. 身分

- 貴族・王族: q0 と q5 を 0.6〜0.8倍、c を 0.6倍(栄養と住居と医療)。ただし男子は戦死と決闘と陰謀が乗る(7-1節、Eisner の君主の暴力死22%が上限の目安)。
- 富裕な平民(大商人など): q0・q5・c を 0.8倍。
- 貧民・都市下層・奴隷: q0・q5・c を 1.3〜1.5倍。
- サイバーパンク型は格差を極端にする: 上層は現代日本以上(e0 90超)、下層は c を 3倍、a30 を 2倍。全体の平均が表の e0 70前後になる。
- 治癒魔法の「届き方」もここで表す。教会や治療院が高額な世界では、貴族の c をさらに 0.7倍、平民は補正なし。

### 7-7. 種族と異能

- 長命種族(エルフなど): b を 0.02〜0.03 まで下げ、max を 300〜1000 にする。ただし q0 と c はそのまま残す(長命でも魔物や事故では死ぬ)。成長と出生間隔も遅くする。
- 短命・多産の種族(小型の獣人など): b を 0.12〜0.15 に上げ、max を 50〜60。q0 も高め。現実の哺乳類で体が小さいほど寿命が短く多産なのと同じ方向。
- 大型の獣人・ドワーフ: b を 0.06、max を 120〜150。
- 仙侠の修行者: 修行段階ごとに a30 を 0.3〜0.1倍にし、max を段階ごとに 150、300、500 と上げる。代わりに修行の失敗(段階を上がる試みごとに 0.05〜0.2 の死亡判定)と門派抗争(c を 2倍)を足す。凡人より長く生きるが、若いうちに死ぬ確率も高い、という形になる。
- ゲーム的世界の高レベル者: レベルごとに c を少し下げる(外傷に強くなる)。例えば c × (1 − 0.01 × レベル)、下限 0.3倍。
- 転生者の特典: 子供期の死をどこまで免除するかは遊び方の判断になる。乳児期に普通に死ぬ可能性を残すと、異世界の厳しさが最初の数年で伝わる。

### 7-8. 魔法医療の効き方の目安

| 魔法医療の種類 | 効く死因 | 補正の目安 |
|---|---|---|
| 外傷の治癒魔法・ポーション | 戦闘・事故・魔物 | c の外因分を 0.5〜0.7倍、q0 はほぼ変えない |
| 浄化・清潔の生活魔法 | 下痢症・感染症 | q0・q5 を 0.7〜0.8倍、都市補正を弱める |
| 解毒魔法 | 毒殺・食中毒・毒虫 | 該当イベントの死亡を 0.3倍 |
| 病気治療の高位魔法(希少) | 感染症全般 | 受けられる身分のみ c を 0.5倍 |
| 蘇生(ごくまれ) | すべて | 一生に一度だけ、死亡判定を1回取り消す(高位聖職者に頼める者のみ) |
