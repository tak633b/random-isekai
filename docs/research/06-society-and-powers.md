# 06 社会と権力 — 異世界の「人生を動かす外側の力」

異世界ものの主人公は、能力だけで人生が決まるわけではない。魔王がいるか、教会が強いか、生まれが貴族か奴隷か、近くにダンジョンがあるか。こうした外側の構造が、何歳で何が起きるか、どう死ぬかの大半を決めている。この文書では、なろう系・ラノベ・JRPG・西洋ファンタジー・SFでよく使われる社会の型を要素ごとに整理し、それが主人公の人生にどう絡むかを書く。

作品固有の設定や名前は使わず、ジャンルの中で何度も繰り返されてきた一般的な型として扱う。

---

## 1. 魔王と魔王軍

### 1.1 魔王の型

- 侵略者としての魔王。人類圏に攻め込む軍事勢力の頂点。古典JRPGの基本形で、世界の緊張度を最大にする。
- 封印された魔王。数百年おきに復活する周期的な災厄。復活の予兆(魔物の増加、瘴気、星の異常)が年単位で進む。
- 統治者としての魔王。魔族の国の王で、人類国家と外交関係にある。和平・冷戦・交易の対象になる。2010年代以降のなろう系で増えた。
- 名ばかりの魔王。人間側の宣伝で悪とされているだけで、実際は差別された種族の代表。真相を知る展開の前提になる。
- 主人公が魔王になる型。魔王に転生する、魔王の座を継ぐ、魔物の国を作るうちに魔王と呼ばれる。
- 複数の魔王。各地に「魔王」級の存在が並立し、序列や会議がある。魔王は称号であって唯一者ではない。
- 不在の魔王。すでに討たれた後の世界。残党、権力の空白、勇者の後始末が物語の種になる。

### 1.2 魔王軍の構成

- 四天王・幹部級。地域ごとの指揮官。中盤の壁、勇者パーティの段階的な敵。
- 魔族の貴族・将軍。人間社会と同じく爵位や派閥を持つことがある。
- 魔物の軍勢。知性の低い魔物を魔族が率いる。スタンピードと結びつけやすい。
- 人間の協力者・内通者。教会や王宮内部の裏切り者。暗殺・陰謀イベントの供給源。
- 魔王の子・後継者。和平ルートや恋愛ルートの相手になりやすい。

### 1.3 主人公の人生への絡み方

- 戦争の時代に生まれると、徴兵・疎開・家族の戦死・故郷の陥落が若年期に起きやすい。
- 魔王軍の侵攻ルート上の村に生まれると、幼少期に村が焼かれる「始まりの悲劇」型の確率が上がる。
- 勇者パーティに選ばれると、魔王討伐の旅が人生の中核になり、死亡率が急上昇する。
- 魔王が倒された後の世代では、残党狩り、復興、英雄の政治利用が中心になる。
- 魔族側に生まれた場合は、人間の勇者が「討伐者」として人生に入り込む。勇者に討たれる死がここで現実的な選択肢になる。

## 2. 勇者

### 2.1 勇者の生まれ方

- 異世界召喚。王国や教会が儀式で別世界の人間を呼ぶ。クラスごと召喚、巻き込まれ召喚、召喚失敗や外れ扱いが派生。
- 神託による選定。神殿の巫女・聖女が神の声として名を告げる。
- 聖剣の選定。台座の剣を抜いた者が勇者。王位継承とも重ねやすい。
- 血統。勇者の家系、勇者の末裔。家の名前が重荷になる。
- 紋章・聖痕の発現。ある年齢で身体に印が出る。幼少期イベントとして使いやすい。
- 職業(ジョブ)としての勇者。洗礼でスキル・職業が判明し、その中に「勇者」がある型。

### 2.2 勇者を取り巻く制度

- 王国による管理。勇者は国家の戦略兵器であり、王族との婚約、監視、行動の制限がつく。
- 教会による権威づけ。勇者は神の使徒であり、教会の政治力の源泉になる。
- 勇者パーティ。剣士・魔法使い・僧侶(聖女)・斥候などの定型。国が人選することも多い。
- 勇者の報酬。爵位、領地、王女との結婚、元の世界への帰還(実際には不可能な場合が多い)。
- 勇者の末路の型。凱旋して英雄、危険視されて暗殺、帰れずに異世界で暮らす、闇落ちして次の魔王になる、伝説として名だけ残る。

### 2.3 勇者の位置づけのバリエーション

- 勇者は本物で、主人公がその仲間。
- 主人公自身が勇者。
- 勇者は傲慢な悪役で、主人公は追放された側。なろう系の追放ものに多い。
- 勇者は使い捨てで、召喚した国のほうが悪。
- 勇者は複数いる。国ごとに勇者がいて、勇者同士が政治的に対立する。

## 3. 聖女

### 3.1 聖女の型

- 教会に認定された治癒・浄化・結界の担い手。国の守りの要。
- 召喚された聖女。異世界から呼ばれる。二人召喚されて片方が「おまけ」扱いされる派生がある。
- 平民出身の聖女。孤児院や村から見出され、貴族社会に放り込まれる。
- 偽聖女。本物が別にいる、あるいは主人公が偽物と断定されて追放される。
- 追放された聖女。国を出た途端に結界が消え、元の国が困る。「ざまぁ」型の定番。
- 聖女の代償型。力を使うたびに寿命や記憶を削る。悲劇的な早死にの理由になる。

### 3.2 聖女と制度

- 教会の所属。教皇・枢機卿・司祭の上下関係の中に置かれる。
- 王太子との婚約。聖女と王族の結合は、教会と王権の同盟を意味する。
- 結界の維持業務。毎日の祈り、地方巡礼、浄化の旅。労働としての聖女。
- 聖女候補の競争。学園や神殿で候補者が競い、嫉妬や陰謀が起きる。

### 3.3 人生への絡み方

- 治癒魔法の素質が出ると、幼少期に神殿へ引き取られる分岐がある。家族と引き離される。
- 青年期に婚約・婚約破棄・追放の三点が連鎖しやすい。
- 中年以降は大司教・修道院長・地方の癒し手など落ち着いた道もあるが、物語では語られにくい。
- 死因では、力の使いすぎ、疫病の最前線での感染、政敵による毒殺、異端認定による処刑が典型。

## 4. 王族と貴族社会

### 4.1 爵位と身分

一般的な西洋風爵位を使うことが多い。上から公爵、侯爵、伯爵、子爵、男爵。その下に準男爵や騎士爵(一代限り)。辺境伯は国境防衛を任された特別な伯爵で、侯爵に並ぶ実力を持つことが多い。

- 王族: 国王、王妃、王太子、王子、王女、王弟(公爵になりやすい)。
- 上級貴族: 公爵・侯爵・辺境伯。王家と姻戚関係を持つ。
- 中級貴族: 伯爵。地方の有力者。
- 下級貴族: 子爵・男爵。財政難、上級貴族の寄子(よりこ)になる。
- 騎士爵・名誉爵位: 平民が功績で得る。冒険者や勇者の仲間が叙爵されるときの入口。
- 平民: 商人、職人、農民、冒険者。
- 奴隷・農奴: 最下層。

### 4.2 貴族社会の典型イベント

- 婚約。幼少期(5〜12歳)に家同士で決まる。本人の意思は基本的に関係ない。
- 婚約破棄。学園の卒業パーティなど公の場で宣言される型がジャンル化している。悪役令嬢ものの出発点。
- 断罪。冤罪を着せられ、爵位剥奪・国外追放・修道院送り・処刑を言い渡される。
- 政略結婚。他国の王族、敵対派閥、格上の家へ。年齢差のある結婚も多い。
- 継承争い。長子と庶子、正妃の子と側妃の子、叔父と甥。毒殺・暗殺・事故死に見せかけた殺人が絡む。
- 社交界デビュー。15〜16歳前後。夜会、舞踏会、お茶会での派閥形成。
- 叙爵と陞爵。功績で爵位を得る、または上がる。冒険者・商人・勇者仲間の出世イベント。
- 廃嫡。無能スキル・魔力なしを理由に家から追い出される。追放ものの貴族版。
- 領地の相続。親の死で若くして当主になる。
- 没落。家の破産、反逆罪への連座、戦争での領地喪失。

### 4.3 王権と派閥

- 王党派と貴族派。中央集権を進める王と、自治を守りたい大貴族の対立。
- 改革派と保守派。平民登用、奴隷解放、魔道具の普及などを巡る争い。
- 外戚の専横。王妃の実家が権力を握る。
- 宰相の陰謀。主人公の冤罪の黒幕になりやすい。
- 王の病・崩御。継承戦争の引き金。

### 4.4 人生への絡み方

- 貴族に生まれると、教育機会・魔力・婚姻の選択肢が広がる一方、暗殺・毒殺・処刑・政争での死亡率が上がる。
- 平民から貴族社会に入る(叙爵、養子、聖女認定、学園の特待生)と、身分差別と嫉妬のイベントが続く。
- 王族の死亡要因は、平民と違って暴力の比重が大きい。実際の欧州君主についても、暴力による死が全死因の約2割にのぼったという研究がある(07の歴史節を参照)。

## 5. 学園もの

### 5.1 学園の型

- 王立魔法学院。貴族と才能ある平民が集まる。入学試験、クラス分け、成績順位。
- 騎士学校・士官学校。軍への道。
- 冒険者学校。ギルド附属の訓練施設。
- 聖女・神官の養成所。神殿附属。
- 研究機関としての学院。賢者の塔、魔導研究所。卒業後に研究者として残る道。
- SF版: 士官学校、企業附属のアカデミー、能力者養成機関。
- 現代異能版: 異能者を集める学園。表向きは普通の高校。

### 5.2 学園のイベント

- 入学試験(10〜15歳)。魔力量や実技で測られ、規格外の結果で騒がれる型が定番。
- クラス分け。身分別か実力別か。最下位クラスから成り上がる型。
- 決闘。貴族の子弟から絡まれ、模擬戦で勝つ。
- 学園対抗戦・武闘大会。
- 課外実習でのダンジョン。想定外の魔物が出て、生徒が死ぬ・主人公が覚醒する。
- 婚約者との関係。同じ学園に婚約者がいて、別の誰かに心を移す。
- 卒業パーティ。婚約破棄イベントの舞台。
- 飛び級・特待生・首席卒業。

### 5.3 人生への絡み方

学園は少年期から青年期初め(10〜18歳)の大きな器になる。学園に入るかどうかで、その後の人脈(仲間・宿敵・婚約者・師匠)の大半が決まる。入らない人生は、村・冒険者・徒弟の道に進む。

## 6. 教会と宗教

### 6.1 宗教の型

- 唯一神教会。教皇を頂点とする巨大組織。国家を超える権力。
- 多神教の神殿。戦神・豊穣神・商業神などそれぞれの神殿がある。職業と信仰が結びつく。
- 女神信仰。転生させた女神そのものが信仰対象になっている。
- 精霊信仰・自然信仰。エルフや獣人の宗教。
- 邪教・魔神崇拝。生贄、禁術、魔王復活を目論む結社。
- 異端審問。教義に反する者(異世界の知識、死霊術、魔族との交流)を裁く。

### 6.2 教会が持つ機能

- 洗礼・鑑定。幼少期にスキルや職業を判定する儀式。人生最初の大きな分岐点として最も使いやすい。
- 治癒。神官の回復魔法は有料で、貧民には届かない。
- 孤児院の運営。孤児出身の主人公の出発点。
- 結婚・葬儀の執行。
- 勇者・聖女の認定。
- 免罪符・献金。腐敗の象徴として描かれやすい。
- アンデッド浄化。墓地・戦場の後始末。

### 6.3 人生への絡み方

- 洗礼で「外れスキル」「無職」と出ると、家族からの冷遇・追放が始まる。逆に「希少スキル」は教会や国による囲い込みの対象になる。
- 異端認定は、知識チートを使う転生者にとって現実的な脅威。処刑・幽閉・逃亡の原因。
- 教会の聖職者として生きる道もある。修道院での静かな一生は、異世界ものでは「まれだが穏やかな人生」として扱える。

## 7. 奴隷制度

### 7.1 奴隷の種類

- 犯罪奴隷。刑罰として奴隷になる。危険労働(鉱山・剣闘士)に回されやすい。
- 借金奴隷。返済で解放される可能性がある。
- 戦争奴隷。敗戦国の民、捕虜。
- 違法奴隷。誘拐された亜人や子ども。闇奴隷商。
- 契約魔法・奴隷紋。命令に逆らうと痛みや死をもたらす魔術的な拘束。
- SF版: 債務労働者、契約で縛られた企業の労働者、遺伝子改造された労働階級、AIや人造人間の所有。

### 7.2 物語上の型

- 主人公が奴隷を買い、仲間にする。なろう系で頻出し、倫理的に議論されやすい型。
- 主人公が奴隷として生まれる・売られる。脱走・解放・成り上がりの物語。
- 奴隷解放を目指す改革者になる。
- 剣闘士として勝ち続けて自由を得る。

### 7.3 人生への絡み方

奴隷として生きる場合、死因は過労・虐待・闘技場・鉱山事故・処分に偏る。寿命は短い。解放イベントは「まれ」に設定し、起きたときの物語価値を高くするのがよい。

## 8. 冒険者ギルドと国

### 8.1 ギルドの型

- 国際組織型。国家から独立し、どの国でも同じランク制度が通用する。国の戦争に介入しない原則を持つ。
- 国家附属型。実質的に国の傭兵管理機関。
- 地方の互助組合型。小さな町の寄り合い所。

### 8.2 ランクと依頼

- ランク制。F〜S、あるいは銅・銀・金・ミスリル・オリハルコンなどの金属名。Sランクは国に数人の戦略級。
- 依頼の種類。薬草採取、討伐、護衛、調査、ダンジョン探索、緊急招集(スタンピード時)。
- 冒険者登録。多くの作品で12〜15歳から登録可能。
- ギルドマスター。元高ランク冒険者が引退後に就く職。中年期イベントの典型。
- 受付嬢。主人公の情報源、恋愛相手、ギルドの顔。

### 8.3 ギルドと国家の関係

- 戦争への参加を巡る対立。国は冒険者を兵として使いたい、ギルドは中立を守りたい。
- 高ランク冒険者の取り込み。叙爵で国に縛る。
- 魔物の素材の流通。ギルドは経済機関でもある。
- 緊急時の指揮権。スタンピードでは騎士団とギルドが共同戦線を張る。

### 8.4 人生への絡み方

冒険者は異世界ものの最も一般的な職業であり、同時に最も死にやすい職業として扱うのが自然。新人の数年間が最大の死亡リスク期で、ランクが上がると死亡率は下がるが、受ける依頼の危険度が上がるので一定の比率で戦死が続く。引退後の道はギルド職員、教官、宿屋・酒場経営、店の開業、貴族のお抱えなど。

## 9. 商会と経済

### 9.1 商会の型

- 大商会。国をまたぐ交易網。貴族と同等の影響力。
- 主人公が興す商会。前世の知識(石鹸、調味料、印刷、簿記、娯楽)で成功する、知識チートの定番。
- 商業ギルド。商人の組合。新規参入を妨げる既得権益として描かれやすい。
- 御用商人。王家や大貴族の調達を担う。
- 闇商人。奴隷・禁制品・魔物素材の密売。

### 9.2 典型イベント

- 行商の旅、盗賊の襲撃。
- 新商品の発明と特許争い、模倣。
- 貴族との取引、踏み倒し。
- 商会の乗っ取り、破産。
- 店を持つ(独立開業)。

### 9.3 人生への絡み方

商人の人生は戦闘職より死亡率が低いが、移動中の盗賊、競合による暗殺、破産による転落がある。老年まで生きる確率が比較的高い職業。

## 10. 亜人と種族差別

### 10.1 典型的な種族

- エルフ: 長命(数百年〜千年)、森、閉鎖的、人間を見下すか、人間に狩られる。
- ドワーフ: 長命(200〜300年程度とされることが多い)、鍛冶、酒、鉱山。
- 獣人: 猫・犬・狼・兎・狐など。身体能力が高く、差別や奴隷化の対象になりやすい。
- 竜人・龍人: 強大、誇り高い、少数。
- 魔族: 人間と敵対することが多い。寿命が長い。
- ハーフ(混血): 両方の社会から排除される。ハーフエルフが典型。
- 小人族(ホビット型): 器用、商人、斥候。
- 人魚、有翼人、鬼人、吸血鬼、スライムや魔物の擬人化。

### 10.2 差別の構造

- 人間至上主義の国(しばしば教会が後ろ盾)。亜人は市民権を持たない。
- 多種族共存の国。主人公が目指す、あるいは作る理想郷。
- 種族ごとの国。エルフの森、ドワーフの山、獣人の連合。
- 亜人狩り。違法奴隷の供給源。

### 10.3 人生への絡み方

- 亜人に生まれると、差別・奴隷化・迫害の死の比重が上がる。
- 長命種に生まれると、人間の友や伴侶を何人も看取る人生になる。逆に人間に生まれて長命種を伴侶にすると、「自分が先に死ぬ」ことが確定した関係になる。
- 混血は「居場所探し」がテーマになりやすい。

## 11. ダンジョン

### 11.1 ダンジョンの型

- 自然発生型。魔力の溜まりから生まれる。
- 遺跡型。古代文明の施設がダンジョン化したもの。
- 生きているダンジョン。核(ダンジョンコア)があり、成長する。攻略で核を壊すと消える。
- ダンジョンマスター型。核を管理する意志ある存在がいて、主人公がそれになる型もある。
- 塔型。上に登る。階層ごとに環境が変わる。
- SF版: 放棄された宇宙ステーション、汚染区域、暴走したAIの管理する施設。

### 11.2 階層と構造

- 浅層: 新人向け。スライム・ゴブリン相当。死亡は油断や事故による。
- 中層: 中堅向け。罠と群れ。パーティの連携が問われる。
- 深層: 高ランク向け。階層主(ボス)、環境災害(溶岩、毒霧、暗闇)。
- 最深部: 未踏。伝説級の魔物、古代の遺物、ダンジョンの核。
- セーフエリア、転移陣、帰還の魔道具、階層ごとのボス部屋。

### 11.3 スタンピードと魔物の暴走

- ダンジョンが溢れる。周期的、あるいは管理不足で起きる。
- 魔物の大移動。森や山からの群れ。季節、上位個体の出現、魔王復活の予兆が原因になる。
- 防衛戦。町の城壁で騎士団と冒険者が迎え撃つ。主人公の名を上げる機会であり、大量の死者が出る場面。

### 11.4 ダンジョン都市

ダンジョンを中心に発展した都市。冒険者、素材商、鍛冶屋、宿屋、治療院、闇市が集まる。経済はダンジョン依存で、スタンピードやダンジョンの枯渇が都市の運命を左右する。生まれ育った場所がダンジョン都市なら、冒険者になる確率は上がる。

### 11.5 人生への絡み方

ダンジョンは冒険者の人生の中心。罠・魔物・崩落・迷子・飢え・仲間の裏切りによる死が起きる場所。初めてのダンジョン、初めての階層突破、仲間の死、ボス討伐、最深部到達を年代ごとのマイルストーンにできる。

## 12. 竜

### 12.1 竜の型

- 災害としての竜。町を焼く。討伐は国家事業。
- 知恵ある古竜。数千年を生き、人語を話す。助言者、試練を与える者。
- 契約竜・騎竜。竜騎士の相棒。
- 竜の卵を孵す型。主人公が育てる従魔。
- 人化する竜。仲間やヒロインになる。
- 竜の素材。鱗・血・心臓は最高級の素材や秘薬。

### 12.2 人生への絡み方

竜は「まれだが決定的な遭遇」として扱う。遭遇したら死ぬ、討伐したら英雄、契約したら人生が変わる。竜殺しの称号は伝説化の条件になる。

## 13. 古代遺跡と失われた文明

- 超古代文明。魔法か科学が今より進んでいた。滅亡の理由は戦争、禁術、神の怒り。
- 遺物(アーティファクト)。現代では作れない武器や魔道具。持ち主を選ぶ。
- 古代の守護者。ゴーレム、自律兵器、番人。
- 封印。古代の魔王や災厄が眠っている。発掘が災いを招く。
- 主人公の前世が古代人、あるいは古代文明が現代地球の延長だった、という種明かし型。

人生への絡み方: 学者・考古学者・トレジャーハンターの職業の中心。発掘による呪い、守護者による死、遺物による覚醒がイベントになる。

## 14. SF世界の権力

### 14.1 企業

- 巨大企業(メガコーポ)。国家より強い。市民権・医療・住居が雇用と結びつく。
- 企業間戦争。私兵、産業スパイ、暗殺。
- 社員番号で管理された人生。就職先で寿命が変わる。
- 企業附属の学校・病院・宗教。

### 14.2 軍

- 星間国家の宇宙軍。士官学校、配属、前線、昇進。
- 傭兵団。
- 強化兵・改造兵。遺伝子改造、サイボーグ化、記憶操作。
- 徴兵制。異星種族との戦争。

### 14.3 AI

- 管理AI。都市や船を動かす。人間に味方するか、管理しすぎるか。
- 反乱AI。人類の敵。
- 相棒としてのAI。主人公の脳内や船に常駐する。
- AIへの転生・意識のアップロード。主人公自身がAIになる型。
- 人造人間・アンドロイドの権利問題。SF版の亜人差別。

### 14.4 その他の構造

- 植民惑星。開拓、疫病、原住生物、地球との断絶。
- 世代宇宙船。生まれてから死ぬまで船の中。
- 宇宙海賊、密輸、辺境の無法地帯。
- 階層都市。上層と下層の格差。
- 現代異能世界: 異能者を管理する政府機関、秘密結社、異能犯罪、表社会への隠蔽。

## 15. 典型的な人間関係

主人公の一生に出入りする人物の型。シミュレーションでは、ある年齢で「出会い」が起き、ある確率で「別れ」(死・裏切り・離脱・結婚・引退)が起きる、という形で管理できる。

### 15.1 仲間

- 幼なじみ。同じ村や家で育つ。最初の仲間か、最初に失う人。
- パーティメンバー。前衛・後衛・回復・斥候。結成・解散・追放がある。
- 戦友。戦争で背中を預けた相手。
- ライバルから仲間へ。学園の決闘相手が後に親友になる。
- 裏切る仲間。宝・名誉・恋・脅迫が理由。

### 15.2 師匠

- 隠居した英雄・賢者。森や山に住んでいる。
- 親や祖父母。家伝の剣術・魔法。
- 学院の教師。
- 魔物や竜が師匠になる型。
- 師匠の死は、主人公が独り立ちするきっかけとして頻出する。師匠の仇討ちも定番。

### 15.3 宿敵

- 同世代のライバル(勇者、貴族の嫡男、同門の兄弟子)。
- 魔王・四天王・その配下。
- 自分を追放した元パーティ。
- 自分を断罪した婚約者・聖女・王太子。
- 家族を殺した仇。
- 自分と同じ転生者。

### 15.4 婚約者・恋人・伴侶

- 政略の婚約者。好意があるとは限らない。
- 幼なじみの恋。
- 助けた相手(王女、奴隷、聖女、町娘)。
- 複数の伴侶(ハーレム・重婚)。貴族や英雄は一夫多妻が許される設定がよく使われる。
- 異種族の伴侶。寿命差の悲哀。
- 伴侶の死、伴侶との死別、伴侶に看取られる死。

### 15.5 従者・部下

- メイド・執事。貴族の家に生まれたときの身近な存在。
- 騎士・護衛。命を張って主人公を守り、死ぬことがある。
- 買った奴隷が従者になる。
- 領地経営期の家臣団・代官。

### 15.6 ペット・従魔・使い魔

- テイムした魔物(スライム、狼、鳥、竜の幼体)。
- 召喚した使い魔・精霊。
- 普通の動物(馬、犬、猫)。
- 従魔の死は大きな感情イベントになる。従魔は主人公より長く生きる場合も短い場合もある。

### 15.7 家族

- 両親。早死に・離散・追放・溺愛・冷遇のどれか。
- 兄弟姉妹。継承の競争相手、守るべき弟妹。
- 子ども。結婚後に生まれる。子が先に死ぬ、子が跡を継ぐ、子に討たれる。
- 孫。老年期のイベント。
- 前世の家族。元の世界への未練として残る。

## 16. シミュレーションへの使い方

### 16.1 世界パラメータ(人生開始時に抽選)

各世界は以下の値を持つ。値の組み合わせで「どんな社会に生まれたか」が決まる。

| パラメータ | 列挙値 | 抽選の目安 |
|---|---|---|
| worldType | fantasy_medieval / fantasy_modernish / jrpg / sf_space / sf_cyber / modern_ability | ファンタジー系 70%、SF 20%、現代異能 10% |
| demonLordState | none / sealed / invading / ruling_nation / defeated_recently / multiple | invading 30%、sealed 20%、ruling_nation 15%、defeated_recently 15%、none 15%、multiple 5% |
| heroSystem | none / summoned / oracle / holy_sword / bloodline / job | summoned 35%、job 20%、oracle 15%、holy_sword 10%、bloodline 10%、none 10% |
| churchPower | weak / normal / dominant / inquisition | normal 50%、dominant 25%、inquisition 10%、weak 15% |
| slavery | none / debt_only / legal / widespread | legal 40%、debt_only 25%、widespread 15%、none 20% |
| raceRelations | coexist / tense / human_supremacy / separated | tense 40%、human_supremacy 25%、coexist 20%、separated 15% |
| guildType | international / state / local / none | international 60%、state 20%、local 15%、none 5% |
| dungeonDensity | none / rare / common / dungeon_city | common 45%、rare 25%、dungeon_city 15%、none 15% |
| warLevel | peace / border_skirmish / regional_war / great_war | peace 35%、border_skirmish 30%、regional_war 25%、great_war 10% |

SF世界では demonLordState を「敵対勢力」(alien_empire / rogue_ai / rival_corp / none)に、churchPower を「企業支配度」に読み替える。

### 16.2 出身パラメータ

| 出身 | 目安の割合(一般世界) | 主な影響 |
|---|---|---|
| 農民・村人 | 50% | 魔物被害・飢饉・徴兵の影響が大きい |
| 町人・職人 | 20% | 疫病・火事・徒弟イベント |
| 商人 | 8% | 商会・行商・盗賊 |
| 下級貴族・騎士家 | 7% | 学園・婚約・戦争の指揮官 |
| 上級貴族・王族 | 2% | 政争・暗殺・政略結婚・処刑 |
| 孤児 | 6% | 教会・孤児院・冒険者 |
| 奴隷 | 4% | 労役・闘技場・解放イベント |
| 亜人の集落 | 3% | 差別・狩り・長命 |

転生もので「主人公補正」を強めたい場合は、貴族・王族の比率を上げる設定を別に用意する(なろう系は貴族転生が多い)。

### 16.3 社会要素から起きるイベントの条件

- 魔王軍の侵攻: demonLordState=invading かつ warLevel が regional_war 以上のとき、村出身者に「故郷の陥落」を年 2〜5% で起こす。
- 勇者選定: heroSystem に応じた年齢で判定。job 型なら洗礼時(5〜10歳)に 0.1〜1%、召喚型なら異世界から来た主人公のみ。
- 聖女認定: 治癒系スキル保持者のうち 5〜10%。認定後、婚約・追放イベントの確率を上げる。
- 婚約破棄・断罪: 貴族出身かつ学園在籍で、卒業年に 5〜15%(悪役令嬢系の世界ではさらに高く)。
- 異端認定: churchPower=inquisition のとき、知識チート系の行動を取るたびに 1〜3% を加算。
- 奴隷落ち: slavery が legal 以上のとき、借金・敗戦・誘拐で発生。亜人・孤児は確率を数倍にする。
- スタンピード: dungeonDensity が common 以上の地域で、10〜30年に一度程度。ダンジョン都市では5〜10年に一度。
- 竜との遭遇: 一生のうちに 2〜5%。遭遇時の結果は死亡・逃走・討伐・契約に分岐。

### 16.4 人間関係の生成

- 幼少期: 家族(必ず)、幼なじみ(60%)、師匠(20%)、ペット(30%)。
- 少年期: 学園の友人またはライバル(学園入学時 80%)、婚約者(貴族 70%、平民 10%)。
- 青年期: パーティメンバー 2〜5人(冒険者なら必ず)、宿敵(30%)、恋人(50%)、従魔(テイマー系なら必ず、他は 10%)。
- 中年期: 弟子(30%)、部下・家臣(領主・ギルドマスターなら必ず)、子(既婚の 70〜80%)。
- 老年期: 孫(子がいる場合 60%)。

各関係には「終わり方」を持たせる: 死別、裏切り、離脱、結婚して去る、主人公より長生きする。長命種の関係者は主人公の死後も残るので、エピローグ文に使える。
