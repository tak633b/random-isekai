# 01 転生・転移の型と主人公の型

異世界ものの導入部(どうやって来たか)と、主人公がどういう立場から始まり、どういう物語の軸を背負うかを整理する。作品名は型を説明するための例としてだけ挙げ、固有の設定や文章は扱わない。

調査の手がかりにしたのは、ピクシブ百科事典・ニコニコ大百科の「異世界転生」「異世界転移」「なろう系」「追放もの」「悪役令嬢」などの項目、TV Tropes の Isekai / Reincarnation / Trapped in Another World / Summoning Ritual / LitRPG 系の項目、英語版・日本語版 Wikipedia の Isekai と LitRPG の項目、それに作品群そのものについての一般的な知識である。

---

## 1. 大きな区分: 転生か、転移か、召喚か

異世界ものの導入はまず三つに分かれる。

| 区分 | 体 | 年齢 | 元の世界との関係 | 典型 |
|---|---|---|---|---|
| 転生 | 新しく生まれ直す | 0歳(または途中)から | 前世では死んでいる | トラック事故→女神→赤ちゃん |
| 転移 | 元の体のまま | 元の年齢のまま | 行方不明扱い。帰還の可能性が話題になる | ある日突然森の中に立っている |
| 召喚 | 元の体のまま(加工されることも) | 元の年齢のまま | 呼ばれた側の都合で連れてこられた | 王城の魔法陣の上に学生が立っている |

転移と召喚の違いは「誰かが意図して呼んだか」。召喚には呼んだ国や組織がいるので、最初から政治の中に放り込まれる。転移は事故や神の気まぐれで、最初は誰も主人公のことを知らない。

日本のウェブ小説では2010年代前半に転生が主流になり、その後「召喚されたが追い出される」「クラスごと転移して一人だけ外れる」など召喚・転移の変形が増えた。韓国ウェブ小説では「小説や ゲームの中に入る(憑依)」「死ぬと過去に戻る(回帰)」が二大潮流で、欧米の LitRPG では「ゲーム的なシステムが現実の地球に降ってくる(システム降臨)」も大きな一派になっている。

## 2. 死に方・来訪のきっかけの型

### 2.1 転生のきっかけ(前世の死因)

| 型 | 中身 | 頻度 | 物語上の意味 |
|---|---|---|---|
| トラック事故 | 子どもや猫をかばって道路に飛び出し、大型車にはねられる | よくある(定番すぎてネタ化) | 善行で死んだので神が埋め合わせをする、という動機づけ |
| 過労死 | ブラック企業で働き詰め、デスクや帰り道で倒れる | よくある | 「今度はのんびり生きたい」というスローライフ志向の根拠になる |
| 通り魔・強盗 | 刺される、撃たれる。誰かを守って、のこともある | たまに | トラックの代わり。理不尽さが強調される |
| 病死 | 長い入院の末に亡くなる。若くして難病で | たまに | 「健康な体で好きに動きたい」という願いの根拠。前世で何もできなかった反動 |
| 神のミス | 神の手違いで寿命が尽きていないのに死んだ | よくある | 補償としてチートを多めにもらえる、の言い訳になる |
| 災害・事故(地震・火事・飛行機・バス) | 大勢と一緒に死ぬ | たまに | 同時に死んだ他の人も転生している可能性が生まれる(後で再会する伏線) |
| 自殺・いじめ | 追い詰められて | まれ(扱いに配慮が要る) | 前世のトラウマを持ち越す重い主人公になる |
| 老衰・大往生 | 前世を生き切って死ぬ | まれ | 老人の精神で子どもをやる型。落ち着いていて達観している |
| 階段から落ちる・餅を喉に詰まらせる等の間抜けな死 | 本人が恥ずかしがる | たまに | コメディ寄りの導入 |
| ゲーム中の死・寝落ち | VRゲームや徹夜ゲームの最中に | たまに | ゲーム世界転生の入口になる |
| 原因不明 | 気づいたら死んでいた、記憶がない | たまに | 死因自体が後半の謎になることもある |

### 2.2 転移のきっかけ

- 光る魔法陣が足元に出て、教室ごと消える(クラス転移の定番)
- 扉・鏡・穴・井戸・古い祠をくぐる(昔ながらの異界訪問の流れ)
- 寝て起きたら森の中。理由の説明はない
- 神の空間に呼ばれ、説明を受けてから送り出される
- 事故の瞬間に光に包まれ、死なずにそのまま飛ばされる(転生と転移の中間)
- 自宅ごと・コンビニごと・家の土地ごと移る(建物転移)
- 自由に行き来できる(行き来型。現代の物を持ち込んで売る話)
- 期間限定・夢の中だけ・寝ている間だけ向こうに行く

### 2.3 召喚の型

| 型 | 中身 | 頻度 | 立場 |
|---|---|---|---|
| 勇者召喚 | 魔王討伐のために国が儀式で呼ぶ | よくある | 初めは厚遇。だが国の道具として扱われる |
| 巻き込まれ召喚 | 本命の勇者の隣にいたせいで一緒に来た | よくある | 「おまけ」扱い。ステータスが低いと城から追い出される |
| 聖女召喚 | 女性が聖女として呼ばれる | よくある(女性向け) | 本命の聖女と比較され、外れ扱いされた側が主人公になる型が多い |
| クラス召喚 | 学級全員が呼ばれる | よくある | 集団の中での序列、裏切り、いじめの持ち越しが軸になる |
| 使い魔召喚 | 魔法学校の生徒が召喚した使い魔として人間が来る | たまに | 立場が極端に低い。主従関係から始まる |
| 個人による召喚 | 魔術師・魔女・神官が個人の目的で呼ぶ | たまに | 召喚者との関係が物語の中心になる |
| 誤召喚 | 儀式の失敗で全然違う人が来る | たまに | コメディ。呼んだ側が困る |
| 奴隷召喚・隷属付き召喚 | 呼んだ瞬間に従属の首輪や契約で縛る | たまに | 自由を取り戻すことが最初の目標 |
| 魔王側の召喚 | 魔王軍が呼ぶ | まれ | 人間の敵側から始まる |
| 復活・英霊召喚 | 過去の英雄の魂として呼ばれる | まれ | 主人公が過去の自分の名声と向き合う |

召喚ものの頻出要素:
- 召喚国は実は悪い(帰還方法はない・魔王は人間の側に都合のいい敵にすぎない・勇者を戦争に使う)
- 呼ばれた直後にステータス鑑定の儀式があり、そこで序列が決まる
- 「元の世界に帰れる」と言われるが嘘である
- 召喚の儀式で生贄や大量の魔力が使われていた
- 同じ世界に過去の召喚者の痕跡(名前・料理・建物・墓)が残っている

### 2.4 その他の来訪

- 憑依: 死にかけている、または死んだ直後の現地人の体に魂が入る。体の元の持ち主の記憶が混ざる
- 入れ替わり: 現地人と魂が交換される。向こうの人間は地球にいる
- 物語の中に入る: 読んでいた小説・遊んでいたゲーム・見ていたアニメの世界に生まれる(後述)
- 世界ごと: 地球に異世界が流れ込む、ゲームのシステムが地球に降ってくる(LitRPG のシステム降臨)
- ダンジョンが地球に出現する: 現代ダンジョンもの。異世界には行かないが同じ道具立て

## 3. 転生の時期: 赤ちゃんから・途中から

| 型 | 中身 | 頻度 | 影響 |
|---|---|---|---|
| 0歳から(記憶あり) | 産まれた瞬間から大人の意識。赤ちゃんのうちから魔力を鍛える | よくある | 幼少期にスタートダッシュ。成長の早さで周りから神童扱い |
| 幼児期に記憶が戻る | 3〜7歳ごろ高熱・頭の怪我・事故で思い出す | よくある | 現地の人格と前世の人格が混ざる。家族は「急に大人びた」と驚く |
| 思春期に記憶が戻る | 10〜15歳、学園入学・婚約破棄・追放の直前などで | よくある(悪役令嬢もの) | すでに問題を抱えた立場から挽回する話になる |
| 成人後に記憶が戻る | 20歳以降。死ぬ寸前・処刑の前夜など | たまに | ほとんどの選択が終わった状態。破滅回避が急務 |
| 死の瞬間に思い出す | その世界の人生の最期に思い出して、死に戻りにつながる | まれ | 回帰ものの入口 |
| 記憶が徐々に戻る | 夢や断片で少しずつ | たまに | 前世の自分が誰だったかが謎として残る |
| 記憶がない | 前世の記憶を持たず、知識やスキルだけが残る | まれ | 「なぜか知っている」違和感。物語後半で判明 |
| 成体で生まれる | 人外転生(スライム・魔物)では最初から一人で動ける | よくある(人外) | 親がいない。最初から生存競争 |
| 卵から | 竜・鳥・虫・爬虫類系 | たまに | 孵化の瞬間が最初の山場 |

## 4. 前世の記憶の有無と影響

前世の記憶がどれだけ残るかは、その後の人生の「チート度」と「人間関係」の両方を左右する。

### 4.1 記憶の量

- 完全に残る: 名前・家族・知識・性格まで全部。もっとも多い
- 知識だけ残る: 自分が誰だったかは曖昧だが、学校で習ったことや仕事の技能は使える
- 断片的: 夢でしか見ない、ときどき既視感がある
- 人格が二重: 現地の人格と前世の人格が並んでいる、または一方が消えた罪悪感がある
- 封印されている: 何かのきっかけで解ける(覚醒イベント)

### 4.2 記憶がもたらすもの(良い面)

- 精神年齢が高いので、子どものうちから計画的に努力できる(幼少期の修行の型)
- 現代の知識で内政・料理・医療・農業・商売を変える(内政チートの土台)
- 原作知識(ゲームや小説の世界なら)で未来を知っている。破滅フラグを避けられる
- 理科の知識を魔法に応用する(燃焼の仕組みを理解すると火魔法が強くなる、という型)
- 前世で鍛えた職能(料理人・医者・エンジニア・営業・自衛官など)がそのまま武器になる

### 4.3 記憶がもたらすもの(悪い面・葛藤)

- 前世の家族への未練、帰れない悲しみ
- 子どもの体に大人の精神が入っているぎこちなさ。同年代と馴染めない
- 現地の価値観(身分制・奴隷・処刑・宗教)を受け入れられず衝突する
- 異世界の人々を「ゲームのキャラ」と見てしまい、後で後悔する
- 前世のトラウマ(いじめ・過労・人間不信)を持ち越す
- 親を「本当の親」と思えない、あるいは思えるようになるまでの過程
- 不自然に賢いので、悪魔憑き・異端として疑われる
- 前世の知識が現地では間違っている(魔法がある分、物理法則が少し違う)

### 4.4 記憶と周囲の関係

- 隠し通す: もっとも多い。ばれたら面倒なので普通の天才として振る舞う
- 打ち明ける: 家族・恋人・親友にだけ話す。信じてもらえる場面が感動の山場になる
- 世間に知られている: 「転生者」「渡り人」「落ち人」として認知されている世界。保護・利用・迫害のどれかの制度がある
- 同郷人との再会: 同じ事故で死んだ人・クラスメイト・前世の家族や恋人が別の誰かとして転生している

## 5. 神・女神との面会

### 5.1 面会の場面の型

| 型 | 中身 | 頻度 |
|---|---|---|
| 白い空間 | 何もない白い場所で神が待っている | よくある |
| 謝罪する神 | 「手違いで死なせてしまった」と頭を下げる | よくある |
| 事務的な神 | 役所の窓口のように淡々と手続きする。順番待ちの列がある | たまに |
| 尊大な神 | 見下した態度。主人公は反発する | たまに |
| 駄女神 | 頼りない・ポンコツ・一緒に異世界に来てしまう | たまに |
| 邪神・怪しい神 | 善意を装っているが裏がある | たまに |
| 面会なし | 神は出てこず、いきなり異世界 | よくある |
| システム音声 | 神の代わりに機械的な声やウィンドウが説明する | よくある(LitRPG・韓国系) |
| 複数の神 | 神々が主人公を取り合う、あるいはそれぞれ加護をくれる | たまに |
| 後から出てくる神 | 転生後に教会で祈ると神の空間に呼ばれる | よくある |

### 5.2 神の動機

- 手違いの補償
- 世界の危機を救ってほしい(魔王・邪神・世界の崩壊)
- 単に面白いから、退屈しのぎ
- 世界の発展が停滞しているので、異なる知識を持ち込みたい
- 魂のリサイクル。地球は魂が多すぎる、向こうは少なすぎる
- 主人公を気に入った(善行を見ていた)
- 神どうしの賭けや遊びの駒
- 主人公の魂が特別(前世で英雄だった、神の血筋)

### 5.3 転生特典の選択場面

| 型 | 中身 | 頻度 |
|---|---|---|
| 好きな能力を一つ | 自分で考えて願う。知恵の見せ所 | よくある |
| リストから選ぶ | カタログ・ポイント制で振り分ける | よくある |
| ガチャ・くじ | ランダムに引かされる | たまに |
| 選ばせてもらえない | 神が勝手に決める、あるいは全部入り | たまに |
| 遠慮して控えめに | 主人公が「普通でいい」と言うが、結果的に規格外になる | よくある(様式美) |
| 欲張る | 全部ほしいと言って、代償をつけられる | たまに |
| 先着順 | クラス全員が同時に選び、遅れた主人公には残り物しかない | たまに |
| 選んだ物と別のもの | 手違いで違うスキルが付く | たまに |
| 交渉 | 神と取引して条件を引き出す | たまに |

特典として願われがちなもの: 健康な体、言語理解、鑑定、アイテムボックス、魔法の才能、裕福な家、美形、長寿、平和な場所、家族への遺産やメッセージ(地球に残した人への配慮)、前世の記憶の保持。

## 6. ゲーム世界・物語世界への転生

### 6.1 悪役令嬢もの

乙女ゲームや少女向け小説の世界に、破滅が決まっている悪役の令嬢として生まれ変わる。日本の女性向けウェブ小説で最大級の流派で、韓国のロマンスファンタジーにも広く広がっている。

型の中身:
- 婚約破棄・断罪・国外追放・処刑・修道院送りという破滅ルートが決まっている
- 記憶が戻るのは幼少期(対策の時間がたっぷりある)か、断罪の場の直前(即興で切り抜ける)
- 回避の方法: 婚約者に近づかない、ヒロインに優しくする、領地経営で手に職をつける、国外に逃げる準備をする
- 結果として攻略対象に好かれてしまう(逆ハーレム化)
- ヒロイン側も転生者で、ゲームの知識で主人公を陥れようとする(転生者どうしの対立)
- 断罪されて追放された後のほうが幸せになる(追放先で隣国の王子に溺愛される)

派生:
- 悪役令息(男性版)
- 悪役の母・継母・姑に転生
- ヒロインのライバルではなく、名前もない侍女・モブ令嬢に転生
- ゲームの最終ボス・闇堕ちキャラに転生
- 主人公(ヒロイン)に転生したが、原作通りに進めたくない

### 6.2 RPG・MMO世界への転生・転移

- 遊んでいたオンラインゲームの自分のキャラのまま転移する(ゲームのアバターの強さを持っている)
- ゲームの知識(隠しダンジョンの場所、最強装備の入手法、イベントの発生時期)で先回りする
- ゲームでは死んでも復活したが、ここでは死んだら終わり、という緊張
- NPC だと思っていた人々が生きた人間だと気づく
- ギルドの仲間や他のプレイヤーも同じように来ている
- ゲームのシステム(ステータス画面、レベル、スキル)がそのまま適用される

### 6.3 小説世界への憑依(韓国系に多い)

- 読者だった主人公だけが結末を知っている
- 原作で序盤に死ぬ脇役に憑依し、死を回避するために動く
- 原作主人公と協力するか、利用するか、張り合うか
- 原作から外れるほど知識が役に立たなくなる(バタフライ効果)
- 作者本人が自分の書いた小説に入る型もある

## 7. 人外転生

人間以外に生まれる型。最初は弱く、進化や成長で強くなっていく。人間社会との距離が物語の軸になる。

| 転生先 | 型の中身 | 頻度 | 生存上の特徴 |
|---|---|---|---|
| スライム | 最弱の魔物からスタートし、捕食や吸収で能力を増やす | よくある | 最初の死亡率は極めて高いが、成長後は不定形で殺しにくい |
| 蜘蛛・虫 | ダンジョンの奥で生まれ、兄弟と共食いしながら生き延びる | たまに | 序盤のサバイバル要素が強い |
| ゴブリン・オーク | 嫌われ者の種族から群れの王になる | たまに | 人間に討伐対象として狙われる |
| 骸骨・アンデッド | スケルトン・リッチとして目覚める | たまに | 老化しない。聖属性と教会に弱い |
| 竜・ドラゴン | 卵から生まれる、または最初から強大 | たまに | 寿命が非常に長い。討伐隊や竜殺しに狙われる |
| 狼・狐・猫などの獣 | 魔獣や聖獣として | たまに | テイマーに従魔として拾われる展開も多い |
| 剣・武器 | 意思を持つ武器になる。使い手を選ぶ | たまに | 自力で動けない。持ち主の生死に左右される |
| 自販機・道具 | 自動販売機・鎧・盾・本など | まれ | 動けないぶん、どう人と関わるかが鍵 |
| 樹木・植物 | 木や花として | まれ | 動けないが寿命は長い |
| ダンジョンそのもの | ダンジョンコアとして生まれ、迷宮を作り冒険者を迎え撃つ | たまに | 核を壊されると死ぬ。拠点防衛型 |
| 魔王 | 魔王として生まれる・魔王の子になる | たまに | 勇者に狙われる宿命 |
| 卵・赤ちゃんドラゴンなどのペット枠 | 人間に飼われる | まれ | 守られるが自由がない |
| 幽霊・精霊 | 体を持たない | まれ | 物理的には死なないが、消滅の危機がある |
| 吸血鬼 | 夜の種族 | たまに | 不老だが日光と聖職者に弱い |
| エルフ・獣人・ドワーフなど亜人 | 人間ではないが人型 | よくある | 寿命が種族で大きく違う。差別の対象になる地域もある |
| 半魔・混血 | どちらの社会にも属せない | たまに | 迫害と孤独 |

人外転生でよくある流れ: 弱い生まれ → 捕食や経験値で進化(進化先を選ぶ場面がある)→ 人型に近づく(人化スキル)→ 人間と交流 → 魔物の国を作る、あるいは人間の街で正体を隠して暮らす。

## 8. 逆転生・逆転移

異世界の人が地球に来る型。

- 異世界の魔王・勇者・聖女・騎士が現代日本に来て、コンビニや電車に驚く
- 異世界で生きた人生を終えて、また地球に戻ってくる(帰還者もの)。向こうで得た力を持ったまま
- 異世界と地球を行き来して、両方で暮らす
- 地球に戻ってきたら時間がほとんど経っていない、または何十年も経っている

ランダムに一生をシミュレートするゲームでは、「異世界で一生を終えた後に地球に戻る」エンディングの分岐として使える。

## 10. 主人公の型(物語の軸)

一人の主人公が複数の型を兼ねることが普通。たとえば「追放されたテイマーがスローライフを送りつつ、実は最強」のように重なる。

### 10.1 境遇から始まる型

| 型 | 中身 | 頻度 | 典型の流れ |

| 無能扱い→実は最強 | 鑑定で外れスキル・ステータス最低と判定されるが、実は規格外 | よくある | 嘲笑→隠れて成長→実力を見せつける |
| 婚約破棄 | 婚約を一方的に破棄される(主に女性主人公) | よくある | 破棄→追放や独立→もっといい相手や居場所を見つける |
| 奴隷スタート | 奴隷として売られる・首輪をつけられる | たまに | 主人に恵まれる/自分で解放する |
| 孤児・捨て子 | 親に捨てられた、親が死んだ | たまに | 師匠や養父母に拾われる |

### 10.4 性格の型

- 鈍感・無自覚(自分の強さや異常さに気づかない。「僕なにかやっちゃいました?」型)
- 慎重・臆病(過剰なまでに準備する。生存率を重視するゲームではこの型が長生きする)
- 合理主義・冷徹(必要なら人を見捨てる)
- 善人・お人好し(困っている人を見捨てられない。厄介ごとを拾う)
- 欲望に正直(金・女・名声)
- 達観した老人の精神
- 皮肉屋・ツッコミ役
- 狂気・戦闘狂
- 平穏志向(目立ちたくないのに目立つ)

### 10.5 女性向けと男性向けの傾向の違い

大まかな傾向として:
- 男性向け: 力・戦闘・成り上がり・ハーレム・ステータス数値が前面に出る
- 女性向け: 悪役令嬢・婚約破棄・聖女・溺愛・生産職・家族の再生が多い。戦闘より人間関係と居場所探し
- 韓国系: 回帰・憑依・システム・塔の攻略・ハンター(現代ダンジョン)。復讐と成長の速度が速い
- 欧米 LitRPG: 数値とシステムの細部を楽しむ。クラスの組み合わせ、レベルアップの瞬間、ビルドの最適化。ダンジョンコアもの、拠点づくり(ベースビルディング)も人気

## 12. よく出てくる「最初の事件」

来てからまず何が起きるか。シミュレーションでは幼少期・来訪直後のイベントにそのまま使える。

- 洗礼の儀・スキル授与の儀で、授かったスキルがみんなの前で発表される
- 魔物に襲われている馬車・村・少女を助ける(最初の出会い)
- 森の中でスライムやゴブリンと戦い、最初のレベルアップ
- 冒険者ギルドに登録し、受付で水晶に手をかざすと規格外の数値が出て騒ぎになる
- 絡んできた先輩冒険者を返り討ちにする
- 盗賊に襲われる、奴隷商人に捕まる
- 召喚国の王に謁見し、魔王討伐を頼まれる
- 鑑定の結果で外れと判定され、城から追い出される
- 実家から勘当される・婚約を破棄される
- 高熱で寝込み、前世の記憶が戻る
- 魔力測定で水晶を割ってしまう
- 地元の村が魔物や疫病や飢饉の危機にある
- 拾った卵が孵る・弱った魔物を助けて従魔にする
- 転移直後に言葉が通じない(言語理解がない場合)
- 召喚された仲間の一人が死ぬ・行方不明になる

## 14. シミュレーションへの使い方

以下はゲームの列挙値と確率の叩き台。頻度の「よくある/たまに/まれ」は、作品群での出現の多さの目安で、ゲームの抽選の重みとしては、よくある=重み10、たまに=重み4、まれ=重み1 くらいから始めるのが扱いやすい。生存率への影響は、来訪直後から成人までの死亡リスクを基準(±0)として、上向き(生き延びやすい)/下向き(死にやすい)を小・中・大の3段で書いた。「大」はおおむね死亡確率の2倍以上か半分以下、「中」は1.3〜2倍、「小」は1.1〜1.3倍程度の変化を想定している。

### 14.1 来訪方式 arrival_type

| 値 | 頻度 | 初期の生存率 | 備考 |
|---|---|---|---|
| reincarnation_baby(赤ちゃんから転生) | よくある | 小さく上向き | 幼児期の病死リスクは現地人並みに乗る。記憶があるぶん事故は減る |
| reincarnation_awaken_child(幼児期に記憶が戻る) | よくある | ±0 | 記憶が戻るまでは現地人と同じ扱い |
| reincarnation_awaken_teen(思春期に記憶が戻る) | よくある | 小さく下向き | すでに抱えた問題(婚約破棄・断罪予定)を引き継ぐ |
| reincarnation_awaken_adult(成人後・死の直前に戻る) | たまに | 中程度下向き | 直後に破滅イベントがあることが多い |
| transfer_wilderness(森・荒野に転移) | よくある | 大きく下向き(最初の1年) | チートなしだと最初の数日が山場 |
| transfer_town(街の近くに転移) | たまに | 小さく下向き | 言語・身分証がない |
| summon_hero(勇者召喚) | よくある | 上向き(初期)→下向き(魔王戦) | 前半は守られ、後半に最大の死亡リスク |
| summon_bystander(巻き込まれ召喚) | よくある | 中程度下向き | 追放イベントにつながりやすい |
| summon_class(クラス召喚) | よくある | ±0 | 仲間の裏切りイベント表を使う |
| summon_saint(聖女召喚) | たまに | 上向き | 戦闘には出ないが政治に巻き込まれる |
| summon_enslaved(隷属付き召喚) | たまに | 中程度下向き | 解放イベントが必要 |
| possession(現地人に憑依) | たまに | ±0 | 元の持ち主の人間関係と借金を引き継ぐ |
| game_world(ゲーム世界転生) | よくある | 中程度上向き | 原作知識で死亡イベントを回避できる。ただし原作から外れると効果が減る |
| villainess(悪役令嬢転生) | よくある | 下向き(断罪まで)→上向き | 断罪イベントを越えれば以後は安定 |
| novel_extra(小説の脇役に憑依) | たまに | 中程度下向き | 原作で死ぬ予定がある |
| monster(人外転生) | たまに | 大きく下向き(幼体期)→大きく上向き(進化後) | 進化イベントの成否で分かれる |
| object(武器・道具・ダンジョンに転生) | まれ | 特殊 | 死ではなく「破壊」で終わる。寿命は極めて長い |
| regression(回帰・二周目) | たまに | 中程度上向き | 前回の死因を避けられる |
| system_descent(システム降臨・現代ダンジョン) | たまに | 大きく下向き(初期) | 周囲の大量死が起きる世界観 |

### 14.2 前世の死因 past_death_cause

重みの目安: truck=10, overwork=8, god_mistake=6, stabbing=4, illness=4, disaster=3, game_death=3, silly_accident=3, unknown=3, old_age=1, (自殺は扱わないか、扱うなら説明なしで「不明」に寄せる)。

死因によって初期の性格傾向を少しずらす使い方ができる:
- overwork → slow_life 志向に重みを足す
- illness → 健康や体の強さを求める特典を選びやすい
- god_mistake → 特典の数を1つ増やす
- old_age → 精神の安定(無謀な行動を減らす=戦闘死を小さく下げる)

### 14.3 記憶の量 memory_level

| 値 | 頻度 | 効果 |
|---|---|---|
| full(全部) | よくある | 前世知識系チートを有効化。望郷イベントあり |
| knowledge_only(知識だけ) | たまに | 前世知識は使えるが、望郷イベントなし |
| fragments(断片) | たまに | 前世知識の効果を半分に |
| delayed(後で戻る) | たまに | 記憶が戻る年齢を別に抽選 |
| none(なし) | まれ | 前世知識なし。前世の死因イベントを後半の謎として使える |

記憶が戻る年齢の候補: 0 / 3〜7 / 10〜15 / 16〜25 / 死の直前。

### 14.4 神との面会 god_meeting

| 値 | 頻度 | 効果 |
|---|---|---|
| none | よくある | 特典は抽選のみ |
| apologetic(謝罪する神) | よくある | 特典+1 |
| bureaucratic(事務的) | たまに | 特典はリストから |
| arrogant(尊大) | たまに | 特典が1つ少ない、または一つが外れ |
| clumsy(駄女神) | たまに | 特典の一つがランダムに化ける。女神が同行する分岐あり |

### 14.10 来訪直後のイベント表 first_events

第12節の各項目をそのまま候補にする。来訪方式ごとに引けるものを絞る:
- 召喚系: 謁見 / ステータス鑑定 / 追放 / 仲間の死
- 転生系: 洗礼の儀 / 高熱で記憶が戻る / 魔力測定で水晶が割れる / 勘当・婚約破棄
- 転移系: 魔物に襲われる / 言葉が通じない / 馬車を助ける / 盗賊・奴隷商
- 人外系: 最初の捕食 / 兄弟との共食い / 冒険者に見つかる / 進化
