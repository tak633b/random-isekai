# Random Isekai 設計

異世界に生まれた(あるいは召喚された)1人の一生を、1年ずつ最後まで進めるブラウザゲーム。
元になったのは Unchosen(実在の統計で、世界のどこかに生まれた1人の一生を生きる)で、骨格は同じ考え方をとる。

- 毎年の生死は確率で引く。確率は「世界の生命表 × 種族 × 身分 × 職業 × 能力 × 転生特典 × その年の出来事」で決まる。
- 出来事ごとに「なぜ」の一行を付ける。死んだときは、その死を引き寄せた数字を書く。
- 人の輪(家族・仲間・師匠・宿敵・従魔)に id と近さ(bond 0〜100)と共有の記憶を持たせる。
- 同じ設定で何百回も生き直し、享年の分布・平均・死因の内訳を出す(「この世界で何年生きられるか」)。
- 絵は canvas でその場に描くピクセルアート。場面 320×100、顔 48×56、立ち絵 32×48。

型の約束は `src/engine/types.ts` にある。調査は `docs/research/` の7本。

## 1. 世界はパラメータ表

16の型(`WorldId`)を持つ。値は research/03 の 5-2節と 5-3節の表をそのまま使う。

| つまみ | 範囲 | 効くところ |
|---|---|---|
| tech | 0〜10 | 就ける職業、飢饉・疫病の起きやすさ、出来事の絞り込み |
| magic | 0〜3 | 魔法職・治癒魔法・魔力暴走。2以上で魔王がいる世界になりうる |
| powers | 0〜3 | 異能の出来事、異能の暴走 |
| danger | 0〜10 | 魔物の死の重み |
| war | 0〜10 | 戦争の起きる確率 (war × 0.012 / 年) |
| medicine | 0〜10 | 病の死の重み、出産の危険 |
| law | 0〜10 | 暴力の死の重み |

生命表の材料は q0・q5・ch・c・a30・b・max の7つ。完全ランダム(`preset: 'random'`)は16型から1つ引く。
画面では magic と powers を上書きでき(魔法のない中世、異能のある宇宙など)、danger と war も動かせる。
magic を上書きしたときは medicine に (新しい magic − 元の magic) × 0.5 を足す(治癒魔法が平民に届くぶん)。

## 2. 死亡率の式

research/03 の 6-1節(ゴンペルツ=メイカム型)と research/04 の 8.3節(種族の老化の速さ)を合わせる。

人間換算の年齢 heq を、成人前は `age × 16 / race.adult`、成人後は `16 + (age − race.adult) × race.k` とする。

その年のハザードを死因の分類ごとに分けて持つ(`Hazard`)。

- 0歳: infant = −ln(1 − q0)。1〜4歳: infant = q5 と q0 から 0〜4歳通しで q5 になる年あたりの値。これは実年齢で数える(赤ん坊の時期は種族によらない)。
- 5歳〜成人まで: ch を、病・事故・魔物に 6:2:2 で分ける。
- 成人後: c(年齢によらない死)を 病・魔物・暴力・事故 に分ける。分け方の重みは 病 (11 − medicine)、魔物 danger、暴力 (10 − law)、事故 2。
- 老い: age = k × a30 × exp(b × (heq − 30))(成人後のみ)。heq が world.max に達するか、実年齢が race.maxAge に達したら必ず亡くなる。
- 種族の E は 病以外の外因(魔物・暴力・事故)と ch にかける。

これに倍率を重ねる。

| 要因 | 効き方 |
|---|---|
| 身分 | 貴族・王族: infant と disease を 0.7、violence と execution が増える。奴隷・孤児・貧民: infant・disease・famine を 1.3〜1.5 |
| 職業 | `jobs.ts` の risk(冒険者は monster ×4、兵士は war の年に従軍、鉱夫は accident ×2 など) |
| 能力 | hp(健康)が低いと disease、power(強さ)が高いと monster・violence・war が下がる |
| 転生特典 | `Cheat.mult` と `aging`。attention が高いと暗殺・断罪・勧誘の出来事が起きやすい |
| レベル | gamey の世界でなくても内部で持ち、monster・war・violence に (1 − 0.01 × level) をかける (下限 0.4) |
| 世界の状態 | 戦争の年(民間人も violence と famine が増える)、大疫病の年(plague)、飢饉の年(famine) |
| 出来事 | `EventDef.risk` はその年だけ足す |
| 選択 | 選択肢の risk と、自動で選ぶときの性格 (慎重・ふつう・無謀) |

確率は q = 1 − exp(−Σハザード)。亡くなったら分類をハザードの比で引き、`DeathDef` から条件に合う文を重みで選ぶ。
死を取り消せる特典(死に戻り・不死の体)があれば、回数が残る限り取り消し、そのことを記録する。

ねらい: 特典なし・平民・人間・選択なしで生きたときの平均享年が、各世界の表の e0 に±3年で一致すること(テストで実測する)。
職業や出来事で上乗せされるぶんは、Unchosen と同じく「その年齢で生きている人の平均が表どおりになる」よう割り戻す係数で合わせる。

## 3. 主人公

選ばなければランダム。`HeroChoice` のどの項目も省略できる。

- 種族: 世界の `races` の重みで引く。召喚は人間だけ。
- 性別、身分(奴隷〜王族、世界ごとの比率で引く)、才能(強さ・魔力・知恵・人望・運・ものづくり・なし)。
- 転生特典: 「なし」もある。世界の magic・tech・powers で選べないものがある。
- 転生の型: 赤ちゃんから / 途中で思い出す / 召喚 / 現地の生まれ。
- 前世の記憶: なし / ぼんやり / はっきり。はっきりだと知恵が高く始まり、乳幼児期の事故が少し減る。
- 前世: 死に方(トラック・過労・病・通り魔・事故・災害・老衰)と仕事。物語の味付け。

## 4. 1年の進め方 (`engine/life.ts` の advanceYear)

1. ハザードを計算して生死を引く。亡くなれば死因を決めて終わる(死の取り消しがあれば使う)。
2. 年を1つ取る。人の輪の全員も年を取り、それぞれの生命表で亡くなることがある(死別の記録)。
3. 世界の状態を進める(戦争の始まりと終わり、疫病、飢饉、魔王の出現と討伐)。
4. 決まった節目: 洗礼・魔力測定(7歳ごろ、スキルが分かる)、前世を思い出す、学院、成人と職業選び、ギルド登録と昇格、結婚、子、隠居。
5. 出来事のデータから、条件に合うものを重みで0〜2件引く。選択肢があれば `pending` に積み、選ぶまで次の年に進まない(auto なら性格で選ぶ)。
6. 能力の自然な変化(年を取ると hp が下がる、職業で power や mind が伸びる)。

## 5. 出来事のデータ (`src/data/`)

文は日英の組で持つ。条件と効果は宣言で書き、コードを書かずに増やせる(`EventDef`)。
死因の文は `DeathDef`。分類(hazard)ごとに、世界・職業・身分で絞って重みで選ぶ。

| ファイル | 中身 |
|---|---|
| `events/fantasy-young.ts` | 剣と魔法の世界の 乳幼児・子ども・十代 |
| `events/fantasy-adult.ts` | 剣と魔法の世界の 大人・中年・老年 |
| `events/noble-eastern.ts` | 貴族社会・学園・悪役令嬢、和風・中華風 (全段階) |
| `events/future.ts` | 産業・近未来・宇宙・現代・文明の後 (全段階) |
| `events/common.ts` | どの世界でも: 転生・記憶・特典・家族・恋・人の輪・老い |
| `deaths.ts` | 死因の文 |

しるし(`flags`)のうちエンジンが意味を持たせるもの:
`baptized`(スキルが分かった) `academy`(学院に通った) `guild`(ギルド登録) `party`(パーティに入った) `exiled`(追放された)
`engaged` `married` `widowed` `knighted` `cursed` `slave`(今奴隷) `freed` `famous` `hero`(勇者になった) `saint`(聖女になった)
`demonKingSlain` `retired` `shop`(店を持った) `lord`(領地を持った) `outed`(特典が知られた)。
これ以外のしるしは、データの中で出来事を連ねるために自由に作ってよい。

置き換え: `{name}` `{friend}` `{companion}` `{mentor}` `{rival}` `{nemesis}` `{lover}` `{spouse}` `{child}` `{familiar}` `{master}` `{disciple}`
`{town}` `{god}` `{beast}` `{job}` `{race}` `{guild}` `{lord}`、死因の文では `{age}` も。
`{mother}` `{father}` は名ではなく「母」「父」(Mother / Father)と続柄で出る。
輪の人の置き換えを使う出来事は、その役の人がいるときだけ起きる(`tie.new` なら新しく作る)。`tie` で触れる出来事も、`new` でなければその人が生きてそばにいるときだけ起きる(亡くなった親・孤児の親の出来事は起きない)。
`tie.dies` を付けると、その出来事でその人が亡くなる(伴侶を看取る・親の葬儀。伴侶なら `married` が外れ `widowed` が立つ)。

## 6. 何回も試す (`engine/trials.ts`)

`runTrials(setup, n)` は、選ばなかった項目を埋めた後の設定(`Hero.setup`)を固定し、seed だけ変えて n 回生きる。
返すのは 享年の配列・平均・中央値・最長・年齢ごとの生存割合・死因の分類の内訳・具体的な死因の上位。
性格(慎重・ふつう・無謀)を変えて比べられる。

## 7. 絵

`types.ts` の `Figure` と `SceneSpec` が材料。見た目は Figure.seed から決める(同じ人は場面でも顔でも同じ色)。

- `ui/scene.ts`: 世界ごとに空・地面・建物の描き分け。場所(家・畑・ギルド・ダンジョン・戦場・学院・神殿・店・鍛冶場・研究所・城・船・荒野・街・墓)。時刻と季節。
- `ui/portrait.ts`: 顔 48×56。種族の耳・角・肌・目、身分で服の飾り。
- `ui/sprite.ts`: 立ち絵 32×48 の全身。職業で服と持ち物(剣・杖・弓・銃・鍬)。
- `ui/look.ts`: seed と種族から色と髪型を決める。

## 8. 画面

タイトル → 世界と主人公を選ぶ(全部おまかせのボタンもある) → 転生の場面(前世の終わりと女神/召喚) → 人生(場面・顔・立ち絵・年表・能力・人の輪・その年の危険の内訳。1年 / 10年 / 最後まで) → 死亡記録(享年・死因・なぜ・最後にそばにいた人・年表) → 同じ設定で何回も試す(100 / 1000回、享年の分布・死因の内訳・慎重と無謀の比較)。
過去の人生は localStorage に残す(サーバは持たない)。日本語と英語。

## 9. 確かめること

- `tsc --noEmit`、`vitest run`(確率の筋: 世界ごとの平均享年が表の e0 に近い、エルフは長く生きる、冒険者は農民より早く死ぬ、特典で死因の内訳が変わる、同じ seed なら同じ人生、保存して再開しても同じ)。期待値は先に走らせて測ってから書く。
- `vite build`、Playwright での通しプレイ(エラー0件、幅 375px ではみ出し0)、スクリーンショット。
